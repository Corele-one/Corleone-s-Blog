## 1.CLI工具
### bat (替代 cat)

- **用法：** `bat <文件名>`

- **场景：** 查看代码文件。它不仅提供**语法高亮**，还能在左侧显示行号，并集成 Git 修改标记（用 `+` 或 `-` 表示行变动）。

### eza (替代 ls)

- **用法：** `eza -la --icons --git`
    
- **场景：** 列出当前目录文件。它可以显示文件的 **Git 状态**（新文件、已修改等），并为不同后缀名配上精美的图标。
	eza --tree  -L 2     树状结构呈现文件

### fd (替代 find)

- **用法：** `fd <关键词>` (例如 `fd config`)
    
- **场景：** 快速找文件。它比原生的 `find` 快得多，默认忽略 `.git` 和 `.gitignore` 里的干扰项，输出结果清晰。
    

### ripgrep (替代 grep)

- **用法：** `rg <搜索内容>`
    
- **场景：** 在整个项目代码库中搜索某个变量或字符串。它是目前最快的文本搜索工具，非常适合在大规模 monorepo 中使用。
    

### fzf (模糊查找器)

- **用法：** `CTRL+R` (搜索历史) 或 `cat **<TAB>` (模糊补全)。
    
- **场景：** 当你记不清某个长命令，或者想在几千个文件中快速选择一个时，`fzf` 提供的交互式过滤界面是救星。
    

### zoxide (智能跳转)

- **用法：** `z <目录名片段>`
    
- **场景：** 替代 `cd`。它会学习你的习惯，比如你常去 `~/Projects/my-awesome-web`，只需输入 `z awe` 即可直达，无需输入冗长路径。

## 2. 开发与系统管理

### lazygit (Git 终端 UI)

- **用法：** 在 Git 仓库目录下输入 `lg` 或 `lazygit`。
    
- **场景：** 批量暂存文件、合并冲突、查看提交历史。它提供了极其直观的 TUI 界面，让复杂的 Git 操作通过几个按键即可完成。
    

### delta (Git Diff 增强)

- **用法：** 配置为 Git 的默认分页器。
    
- **场景：** 在执行 `git diff` 时，它能提供**侧边对比视图**和语法高亮，让代码 review 变得像在 VS Code 里一样清晰。
    

### btop (系统监控)

- **用法：** 输入 `btop`。
    
- **场景：** 查看 CPU、内存、进程和网速。比传统的 `top` 或 `htop` 更漂亮，支持鼠标点击操作，且能实时渲染动态曲线。
    

### jq (JSON 处理器)

- **用法：** `curl <API地址> | jq '.'`
    
- **场景：** 处理复杂的 JSON 数据。它可以对 JSON 进行格式化、过滤、提取特定字段，是后端开发和运维的标配。
    

### tldr (简化版帮助手册)

- **用法：** `tldr <命令名>` (如 `tldr tar`)
    
- **场景：** 当你忘记某个命令（如 `tar`）复杂的参数时，`tldr` 不会给你丢出几百行的文档，而是直接给最常用的 5 个例子。
    

### fnm (Node.js 管理器)

- **用法：** `fnm use 20`, `fnm install 22`。
    
- **场景：** 极速切换 Node 版本。由于是 Rust 编写，它比 `nvm` 快得多，几乎感觉不到 Shell 启动的延迟。
    

### Zellij (终端复用)

- **用法：** 输入 `zellij`。
    
- **场景：** 在一个 Ghostty 窗口内进行多窗口分割、标签页管理。即使你不小心关掉了终端，再次连接时 Zellij 依然保持着你之前的布局和任务。
