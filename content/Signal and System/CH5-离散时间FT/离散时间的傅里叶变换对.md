| **信号 x[n]**                                         | **傅里叶变换 X(ejω)**                                                                                                        | **级数系数 ak​ (若为周期)**                                                                    |
| --------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| $\sum_{k=\langle N \rangle} a_k e^{j k (2\pi/N) n}$ | $2\pi \sum_{k} a_k \delta(\omega - \frac{2\pi k}{N})$                                                                   | $a_k$                                                                                  |
| $e^{j\omega_0 n}$                                   | $2\pi \sum_{l} \delta(\omega - \omega_0 - 2\pi l)$                                                                      | $\begin{cases} 1, & k=m \pm rN \\ 0, & \text{其他} \end{cases}$ (注1)                     |
| $\cos \omega_0 n$                                   | $\pi \sum_{l} [\delta(\omega - \omega_0 - 2\pi l) + \delta(\omega + \omega_0 - 2\pi l)]$                                | $\begin{cases} \frac{1}{2}, & k=\pm m \pm rN \\ 0, & \text{其他} \end{cases}$ (注1)       |
| $\sin \omega_0 n$                                   | $\frac{\pi}{j} \sum_{l} [\delta(\omega - \omega_0 - 2\pi l) - \delta(\omega + \omega_0 - 2\pi l)]$                      | $\begin{cases} \frac{1}{2j}, & k=m \pm rN \\ -\frac{1}{2j}, & k=-m \pm rN \end{cases}$ |
| $x[n] = 1$                                          | $2\pi \sum_{l} \delta(\omega - 2\pi l)$                                                                                 | $a_k = 1$ (对于 $k=0, \pm N, \dots$)                                                     |
| **周期方波** (注2)                                       | $2\pi \sum_{k} a_k \delta(\omega - \frac{2\pi k}{N})$                                                                   | $\frac{\sin[(2\pi k/N)(N_1 + 1/2)]}{N \sin(2\pi k/2N)}$                                |
| $\sum_{k} \delta[n - kN]$                           | $\frac{2\pi}{N} \sum_{k} \delta(\omega - \frac{2\pi k}{N})$                                                             | $a_k = \frac{1}{N}$                                                                    |
| $a^n u[n], \lvert a \rvert < 1$                     | $\frac{1}{1 - a e^{-j\omega}}$                                                                                          | —                                                                                      |
| **矩形脉冲** (注3)                                       | $\frac{\sin[\omega(N_1 + 1/2)]}{\sin(\omega/2)}$                                                                        | —                                                                                      |
| $\frac{\sin Wn}{\pi n}$                             | $X(e^{j\omega}) = \begin{cases} 1, & 0 \le \lvert\omega\rvert \le W \\ 0, & W < \lvert\omega\rvert \le \pi \end{cases}$ | —                                                                                      |
| $\delta[n]$                                         | $1$                                                                                                                     | —                                                                                      |
| $u[n]$                                              | $\frac{1}{1 - e^{-j\omega}} + \sum_{k} \pi \delta(\omega - 2\pi k)$                                                     | —                                                                                      |
| $\delta[n - n_0]$                                   | $e^{-j\omega n_0}$                                                                                                      | —                                                                                      |
| $(n+1) a^n u[n]$                                    | $\frac{1}{(1 - a e^{-j\omega})^2}$                                                                                      | —                                                                                      |
| $\frac{(n+r-1)!}{n!(r-1)!} a^n u[n]$                | $\frac{1}{(1 - a e^{-j\omega})^r}$                                                                                      | —                                                                                      |
- **注1 (周期性判定)**：对于离散正弦/复指数信号，只有当 $\frac{\omega_0}{2\pi}$ 为**有理数**时，信号才是周期的。表中系数 $a_k$ 假设了 $\omega_0 = \frac{2\pi m}{N}$。
- **注2 (周期方波)**：周期为 $N$，在一个周期内，当 $\lvert n \rvert \le N_1$ 时 $x[n]=1$，其余为 $0$。其系数 $a_k$ 呈现出离散的类似 $\text{sinc}$ 的形状。
- **注3 (非周期矩形脉冲)**：这是数字信号处理中最常用的变换之一。注意分母是 $\sin(\omega/2)$ 而非 $\omega/2$，这是离散时间域与连续时间域的主要区别。
