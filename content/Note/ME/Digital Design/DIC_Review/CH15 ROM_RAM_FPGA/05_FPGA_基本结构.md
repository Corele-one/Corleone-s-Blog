# 05 FPGA 基本结构

## 1. FPGA 的基本概念

FPGA 是现场可编程门阵列。它不是固定功能芯片，而是由大量可配置逻辑块、触发器、可编程互连、I/O 块和专用硬件资源组成。用户通过配置比特流决定其逻辑功能和连接关系。

FPGA 常用于：

- 数字逻辑原型验证。
- 高速接口和数据处理。
- 自定义加速器。
- 控制逻辑、通信协议、图像/信号处理。

## 2. FPGA 的主要资源

以 Xilinx 7-Series FPGA 为例，常见资源包括：

- CLB：Configurable Logic Block，可配置逻辑块。
- LUT：Look-Up Table，查找表，用于实现组合逻辑。
- FF：触发器，用于实现时序逻辑。
- Slice：CLB 内部更小的逻辑组织单元。
- I/O Block：输入输出块，负责与外部引脚连接。
- Block RAM：片上块 RAM。
- DSP Slice：乘加、滤波等算术运算资源。
- Clock Resource：时钟树、PLL/MMCM、时钟缓冲等。
- Programmable Interconnect：可编程互连资源。

## 3. LUT 的作用

LUT 可以看成一个很小的 ROM。若 LUT 有 `k` 个输入，则它可以存储 `2^k` 个输出值。配置比特决定每一种输入组合对应的输出，因此一个 `k` 输入 LUT 可以实现任意 `k` 输入组合逻辑函数。

例：3 输入 LUT 可以实现任意 3 变量逻辑函数，因为它有：

```text
2^3 = 8
```

个输入组合，需要 8 个配置位描述输出真值表。

## 4. CLB、Slice 与互连

CLB 是 FPGA 中实现普通逻辑的基本区域。CLB 内部包含若干 Slice，每个 Slice 包含 LUT、触发器、进位链、多路选择器等资源。

互连资源决定不同 CLB、I/O、RAM、DSP、时钟资源之间如何连接。FPGA 的灵活性很大程度来自可编程互连，但互连延迟也是 FPGA 时序设计中的重要限制。


## 5. I/O Block

I/O Block 负责外部引脚与内部逻辑之间的连接，通常支持：

- 输入缓冲和输出缓冲。
- 三态控制。
- 输入/输出寄存器。
- I/O 延迟调整。
- 不同电平标准。
