# 04 DRAM 与 SDRAM

## 1. DRAM 存储单元

DRAM 是动态 RAM。一个基本 DRAM 单元通常由一个晶体管和一个电容构成，信息存储在电容电荷中。

DRAM 的特点：

- 单元结构简单，密度高，成本低。
- 电容会漏电，必须周期性刷新。
- 读操作可能破坏原有电荷，因此读后需要恢复。
- 常用于主存、大容量存储。

## 2. SDRAM

SDRAM 是同步 DRAM，它用时钟控制命令、地址和数据传输。内部通常包含多个 bank，每个 bank 有行译码、列译码、感放器和存储阵列。

常见 SDRAM 命令：

| 命令 | 作用 |
|---|---|
| NOP | 无操作 |
| ACTV / ACTIVE | 激活指定 bank 的一行 |
| READ | 发起读操作 |
| WRITE | 发起写操作 |
| PRE / PRECHARGE | 预充电，关闭已激活行 |
| REF / REFRESH | 刷新 |

SDRAM 读操作通常包括：

```text
PRECHARGE -> ACTIVE -> READ -> 数据输出
```

其中需要满足预充电到激活延迟、行到列延迟、CAS 延迟等时序参数。

SDRAM 写操作通常包括：

```text
PRECHARGE -> ACTIVE -> WRITE -> 数据输入
```


## 3. SRAM、DRAM、SDRAM 对比

| 项目 | SRAM | DRAM | SDRAM |
|---|---|---|---|
| 存储机理 | 锁存器/触发器式结构 | 电容存储电荷 | 同步控制的 DRAM |
| 是否刷新 | 不需要 | 需要 | 需要 |
| 是否同步 | 可异步或同步 | 传统 DRAM 多为异步控制 | 同步 |
| 速度 | 快 | 相对慢 | 通过同步和突发传输提高吞吐 |
| 密度 | 较低 | 高 | 高 |
| 成本/bit | 高 | 低 | 低 |
| 典型用途 | Cache、片上 RAM、高速缓冲 | 主存基础技术 | 主存、图像缓冲、大容量同步存储 |
