# 03 RAM、SRAM 与 SSRAM

## 1. RAM 的基本结构

RAM 是随机存取存储器，可以读也可以写。一个典型 RAM 表示为：

![[file-20260702110712806.png|300]]

```text
2^n x b RAM
```

其接口通常包括：

- 地址输入：选择要访问的存储单元。
- 数据输入：写入时使用。
- 数据输出：读出时使用。
- 控制输入：如 `CS`、`OE`、`WE`。

## 2. SRAM 存储单元

SRAM 是静态 RAM。它通常用交叉耦合反相器或等效锁存结构保存 1 bit 数据，只要电源存在且没有被改写，数据就能保持，不需要周期性刷新。
[[02_锁存器和触发器#D锁存器]]

![[file-20260702110810363.png|762]]

|信号|作用|
|---|---|
|**IN**|数据输入，送入 D 锁存器的 D 端|
|**SEL_L**（低有效）|片选/行选信号，选中该单元时才允许读写|
|**WR_L**（低有效）|写使能，低时允许写入|
|**OUT**|数据输出，经三态缓冲器控制|
SRAM 的特点：

- 读写速度快。
- 不需要刷新。
- 每 bit 所需晶体管较多，密度低于 DRAM。
- 常用于高速缓存、片上 RAM、小容量高速存储。

## 3. 异步 SRAM
异步 SRAM 没有统一时钟控制。读写操作由地址、片选、输出使能、写使能等信号的电平和时序关系决定。

读操作一般过程：

1. 地址稳定。
2. `CS` 有效，选中芯片。
3. `OE` 有效，允许输出。
4. 等待访问时间后，数据输出有效。

写操作一般过程：

1. 地址稳定。
2. 数据输入稳定。
3. `CS` 有效，`WE` 有效。
4. 满足写脉宽、地址建立/保持、数据建立/保持等时序要求。


## 4. SSRAM

SSRAM 是同步 SRAM。它使用时钟采样地址、数据和控制信号，常见于高速系统。

SSRAM 的特点：

- 地址、控制、数据通常在时钟边沿被寄存。
- 读写操作与时钟周期对齐。
- 时序分析更适合同步系统设计。
- 相比异步 SRAM，更容易在高速总线或流水线系统中使用。

## 5. SRAM 与 SSRAM 对比

| 项目 | 异步 SRAM | SSRAM |
|---|---|---|
| 是否使用时钟 | 不使用统一时钟 | 使用时钟 |
| 信号采样 | 由地址/控制信号电平和延迟决定 | 在时钟边沿采样 |
| 适用场景 | 中低速异步接口、简单存储扩展 | 高速同步系统、流水线总线 |
| 设计重点 | 访问时间、建立保持、控制脉宽 | 时钟周期、时钟到输出、建立保持 |
