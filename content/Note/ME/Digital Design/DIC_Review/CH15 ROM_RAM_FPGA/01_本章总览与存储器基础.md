# 01 本章总览与存储器基础

## 1. 本章学习目标

本章围绕数字系统中的两类核心硬件资源展开：

- 存储器：ROM、RAM，以及 SRAM、SSRAM、DRAM、SDRAM 等不同实现。
- FPGA：以 Xilinx 7-Series FPGA 为例，理解可编程逻辑、I/O、互连和片上资源的基本结构。

需要重点掌握：

- ROM 与 RAM 的基本结构和工作原理。
- ROM、SRAM、SSRAM、DRAM、SDRAM 的区别。
- 存储器容量、地址位宽、输入/输出数据位宽之间的关系。
- 能够根据规格计算存储器容量、地址线数量、数据线数量或需要的芯片片数。
- FPGA 的基本组成：逻辑块、查找表、触发器、I/O 块、互连资源、片上 RAM/DSP/时钟资源等。

## 2. 存储器的基本表示方法

存储器通常写成：

```text
2^n x b
```

含义：

- `n`：地址输入位数。
- `2^n`：可寻址的存储单元个数，也称为字数或地址深度。
- `b`：每个地址存储或输出的数据位数，也称为字长或数据位宽。
- 总容量：`2^n x b` bit。

常见换算：

```text
1 Byte = 8 bit
1 KB = 2^10 Byte
1 MB = 2^20 Byte
1 Gb = 2^30 bit
```

例：一个 `2^10 x 8` 的存储器有 `1024` 个地址，每个地址 8 bit，总容量为：

```text
2^10 x 8 bit = 8192 bit = 1024 Byte = 1 KB
```

## 3. 容量、地址位宽、数据位宽计算

若存储器规格为：

```text
深度 x 字长 = 2^n x b
```

则：

```text
地址位宽 n = log2(深度)
数据位宽 b = 每个地址的数据位数
总容量 bit = 深度 x 字长
总容量 Byte = 总容量 bit / 8
```

如果总容量和字长已知：

```text
深度 = 总容量 bit / 字长
地址位宽 = log2(深度)
```

如果深度不是 2 的整数次幂，实际地址位宽通常取：

```text
地址位宽 = ceil(log2(深度))
```

这会产生部分未使用地址。

## 4. 例题

### 例题 1：由地址位宽和数据位宽求容量

某 ROM 有 12 根地址线、8 根数据输出线，求容量。

```text
地址数 = 2^12 = 4096
每个地址 8 bit
总容量 = 4096 x 8 bit = 32768 bit = 4096 Byte = 4 KB
```

答案：`4K x 8`，总容量 `4 KB`。

### 例题 2：由容量和数据位宽求地址线

某 RAM 容量为 `64 KB`，数据位宽为 `8 bit`，求地址线数量。

```text
64 KB = 64 x 1024 Byte = 65536 Byte
数据位宽 8 bit = 1 Byte
深度 = 65536 个地址 = 2^16
地址线 = 16 根
```

答案：16 根地址线。

### 例题 3：扩展数据位宽

已有 `8K x 8` RAM 芯片，要组成 `8K x 32` 存储器，需要几片？

```text
片数 = 32 / 8 = 4
```

答案：4 片，并联扩展数据位宽。深度相同，地址线共用，每片提供 8 bit 数据。

### 例题 4：扩展地址深度

已有 `8K x 8` RAM 芯片，要组成 `32K x 8` 存储器，需要几片？

```text
片数 = 32K / 8K = 4
```

答案：4 片。低位地址接各芯片地址端，高位地址通过译码器产生片选信号。
