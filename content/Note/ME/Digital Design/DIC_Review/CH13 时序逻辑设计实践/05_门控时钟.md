# 05 门控时钟

门控时钟 clock gating 用于降低动态功耗：当某个模块暂时不需要更新时，让该模块的时钟停止翻转。

门控时钟本身是工程中常见技术，但如果实现方式错误，会引入毛刺、窄脉冲和不可控 skew，反而导致严重时序问题。

## 错误门控时钟

最直接但危险的写法是：

```text
GCLK = CLK AND CLKEN
```

如果 `CLKEN` 在 `CLK` 高电平期间变化，`GCLK` 可能产生短脉冲或毛刺。触发器可能把这些毛刺当成有效时钟边沿，从而错误采样。

![[file-20260702102826897.png]]

错误门控时钟的风险：

- 产生毛刺时钟。
- 生成不满足最小高/低电平宽度的窄脉冲。
- 时钟延迟和 skew 不可控。
- 后端 CTS 和 STA 难以正确识别和分析。
- FPGA 中用 LUT 生成局部时钟会破坏专用时钟网络。

## 可接受的门控时钟

可接受的门控方式要求使能信号只在安全窗口变化。常见做法是在时钟低电平期间锁存 `CLKEN`，再与时钟组合，从而避免 `GCLK` 在高电平期间出现毛刺。

ASIC 中通常使用标准单元库提供的 ICG integrated clock-gating cell，而不是手写普通与门。

## 设计原则

- 优先使用库提供的 ICG 单元。
- 门控使能必须满足门控单元的 setup/hold 要求。
- 门控单元必须进入时钟树综合和静态时序分析。
- FPGA 中优先使用寄存器自带 clock enable，而不是生成新时钟。
- 不要在多个层级随意派生大量局部时钟，除非时钟约束和 CDC/STA 都已明确处理。

## 与 clock enable 的区别

clock enable 不关闭时钟，只是在触发器内部控制是否更新状态：

```text
if EN = 1:
    Q_next = D
else:
    Q_next = Q
```

门控时钟则是真的让时钟停止翻转：

```text
if EN = 1:
    GCLK follows CLK
else:
    GCLK stays inactive
```

clock enable 通常更安全、更容易分析；门控时钟能省更多动态功耗，但必须严格按工艺库和工具流程实现。
