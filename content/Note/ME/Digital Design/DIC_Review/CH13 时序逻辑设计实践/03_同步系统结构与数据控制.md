# 03 同步系统结构与数据控制

同步系统通常由数据处理部分 datapath 和控制部分 control 组成。数据处理部分负责“数据在哪里、怎么运算、写到哪里”，控制部分负责“每个时钟周期做什么”。

## 同步系统基本结构

同步系统中，状态只在时钟有效边沿更新。组合逻辑在两个时钟边沿之间完成计算。

```text
状态寄存器/数据寄存器 -> 组合逻辑 -> 下一状态/结果寄存器
          ^                                |
          |                                v
                同一个系统时钟采样
```

## 数据处理部分

数据处理部分负责存储、选择、运算和传输数据，常见模块包括：

- 寄存器组。
- 计数器。
- 移位寄存器。
- 加法器、减法器、比较器。
- MUX、多路选择器。
- ALU。
- 数据总线。

数据处理部分的关键问题是：每个周期数据从哪里来、经过什么逻辑、写到哪里。

## 控制部分

控制部分通常是有限状态机 FSM，负责产生控制信号。

常见控制信号：

- `load`：寄存器装载。
- `clear`：寄存器清零。
- `enable`：寄存器或计数器使能。
- `sel`：MUX 选择。
- `start` / `done`：启动与完成。
- `valid` / `ready`：握手。

控制器的关键问题是：系统当前处于什么状态，下一周期进入什么状态，本周期给数据通路发出哪些控制信号。
## 设计流程

1. 明确功能需求和每个周期的数据操作。
2. 画数据通路：寄存器、运算单元、MUX 和总线。
3. 画控制状态机：状态、转移条件、每个状态的控制输出。
4. 标出关键时序路径：从一个寄存器 `Q` 到另一个寄存器 `D`。
5. 检查时序：setup、hold、clock skew、clock gating、CDC。

## 学习要点

- 数据通路决定“算什么”，控制器决定“什么时候算”。
- 控制信号本身也必须满足时序要求，不能在采样边沿附近抖动。
- 如果数据通路组合逻辑太长，通常需要流水线分割。
- 同步系统中状态更新应集中在时钟边沿，避免无意引入锁存器或异步反馈。
