# 电容的VCR
电容属于储能元件，其两端电流电压关系满足：
$$I(t)=\frac{dq(t)}{dt}=\frac{C\times du(t)}{dt}$$
并且电容的电流相位超前电容电压的相位90度（在复频域里，求微分相当于✖️一个jw，即频率超前90度），即电容的电压不能突变，电流可以突变，因为如果电压突变的话，那么流过电容的电流就会无限大。
# 电容记忆性
电容的记忆性体现在其电压表达式
$$u(t2)=\frac{1}{C}\int_{t1}^{t2} i(t) \,dt + u(t1)$$
电容t2时刻的电压都和它过去所有时间流过的电流有关，因此q被称为电容的状态变量
# 电容储能
$$w_E(t)=\frac{CU(t)^2}{2}$$
# 电容电压不能突变
当电流有界时，电容两端的电压不能突变
$$u_c(t+)=u_c(t-)$$
