在 FPGA 和数字电路设计中，三段式状态机(FSM)被公认为是最规范、可读性最强且时序最稳定的写法。相比于一段式（逻辑混乱）和二段式（组合输出易产生毛刺），三段式将状态跳转、组合逻辑和寄存器输出完全分离。

---

## 三段式状态机的核心结构

所谓“三段”，是指通过三个 `always` 模块来实现不同的功能：

1. **第一段（同步时序逻辑）**：描述状态寄存器的状态转换（Current State $\leftarrow$ Next State）。
    
2. **第二段（组合逻辑）**：根据当前状态和输入信号，决定下一个状态是什么（Next State = $f$(State, In)）。
    
3. **第三段（同步时序逻辑）**：描述输出逻辑。**关键点在于输出也进入寄存器**，以消除组合逻辑产生的毛刺。
    

---

## 注意事项（避坑指南）

在使用三段式写法时，必须严格遵守以下规则：

|**关注点**|**要求**|**原因**|
|---|---|---|
|**赋值方式**|第一段和第三段用**非阻塞赋值（`<=`）**；第二段用**阻塞赋值（`=`）**。|防止时序违规，确保逻辑符合设计预期。|
|**敏感列表**|第二段必须使用 `always @(*)`。|确保输入或当前状态改变时，下一状态能立即计算。|
|**防止 Latch**|第二段的 `case` 语句必须包含 `default`，且每个分支内所有信号都要赋值。|避免在组合逻辑中意外生成锁存器（Latch），影响时序分析。|
|**状态编码**|建议使用 `localparam` 定义状态名。|增加代码可读性，便于后续维护。|
|**复位逻辑**|第一段必须有明确的复位初始状态。|确保电路在上电或复位后处于受控的已知状态。|

## 三段式状态机标准模板

以一个简单的序列检测器（检测 `in` 是否连续出现两个 `1`）为例：

Verilog

```
module fsm_three_stage (
    input  clk,
    input  rst_n,
    input  in,
    output reg out
);

    // 1. 定义状态名 (使用 localparam)
    localparam IDLE = 2'b00,
               S1   = 2'b01,
               S2   = 2'b10;

    reg [1:0] curr_state;
    reg [1:0] next_state;

    // --- 第一段：状态寄存器（时序逻辑） ---
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            curr_state <= IDLE;
        else
            curr_state <= next_state;
    end

    // --- 第二段：下一状态决策（组合逻辑） ---
    always @(*) begin
        // 初始值设定，防止生成 Latch
        next_state = IDLE; 
        case (curr_state)
            IDLE: begin
                if (in) next_state = S1;
                else    next_state = IDLE;
            end
            S1: begin
                if (in) next_state = S2;
                else    next_state = IDLE;
            end
            S2: begin
                if (in) next_state = S2;
                else    next_state = IDLE;
            end
            default: next_state = IDLE;
        endcase
    end

    // --- 第三段：输出逻辑（时序逻辑，寄存器输出） ---
    // 这种写法比二段式好在：out 是经过时钟打拍的，没有毛刺，时序路径更好
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            out <= 1'b0;
        end else begin
            case (next_state) // 注意：这里通常看 next_state 来实现当前时钟沿后的输出
                S2:      out <= 1'b1;
                default: out <= 1'b0;
            endcase
        end
    end

endmodule
```

---

## 为什么推荐三段式？

1. **时序优化**：第三段将输出信号寄存器化（Registered Output）。在高速设计中，这能有效缩短组合逻辑路径，提高系统最高主频（$F_{max}$）。
    
2. **代码结构清晰**：状态转换和输出逻辑各司其职。如果你需要修改输出条件，只需改动第三段；如果需要修改状态跳转，只需改动第二段。
    
3. **调试方便**：在仿真时，`curr_state` 和 `next_state` 分离，能非常清楚地看到状态机是在哪个周期发生了跳转，以及预判下一个状态。
    

> **Tips**:
> 
> 在第三段逻辑中，如果使用 `case(next_state)`，输出会在状态跳转的**同一个周期**发生变化（同步）；如果使用 `case(curr_state)`，输出会比状态跳转**晚一个周期**。根据你的实际需求选择即可。
