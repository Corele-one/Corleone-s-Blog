## 行波计数器
一个T触发器(时钟边沿到来时输出翻转)实际上就是一个模为2的计数器
![[file-20260514104212237.png|365x480]]
其中低位的Q‘作为高位的时钟，当低位从1->0的时候，需要向前进位，所以说把Q‘(从0->1为上升沿)作为时钟接入高位的时钟，就能实现像高位的进位。
如果要实现==减法==的计数器的话，只需把Q端作为时钟接入高位即可。

但是本质上这种计数器的构成方式还是异步的，在真实情况下，我们希望得到一个同步的计数器。因为如果采用异步计数器的话，每个触发器需要等它前一级完成翻转后才能触发，会造成延时并且位数越多延时越大。

时钟周期需要>所有触发器延时之后，否则在低位没有稳定的时候下一个时钟沿又来了。
## 同步四位二进制计数器
在同步计数器中，所有触发器都共用一个CLK信号，因此在经过仅仅$t_{TQ}$的延迟后，所有触发器的输出同时发生变化。此时采用带有使能输入端的T触发器。
![[file-20260514111527353.png|595x424]]
并且注意使能端相连接的与门的接法，需要在低位都满的时候，才使能高位的级数功能，不然会出现以下这种情况：

## 4位通用二进制计数器CNTR4U
![[file-20260514111805950.png|516x352]]
其中，ENP为计数使能，ENT为进位使能，LD为置数使能，CLR为清零使能，用verilog语言描述该模块的功能如下：
```Verilog
modeule Vrcntr4u(CLK,CLR,LD,ENP,ENT,D,Q,RCO);
	input CLK,CLR,LD,ENP,ENT;
	input [3:0] D;
	output reg [3:0] Q;
	output reg RCO;
	//创建该计数器的特性
	always @(posedge CLK) begin
		if(CLR == 1) begin
			Q<=4'd0;
		end
		else if(LD==1) begin
			Q<=D;
		end
		else if((ENP==1)&&(ENT==1)) begin
			Q<=Q+1;
		end
		else begin
			Q<=Q;
		end
	end
	//创建组合输出RCO
	always@(Q or ENT) begin
		if((ENT==1)&&(Q==4'd15)) begin
			RCO=1;
		end
		else begin
			RCO=0;
		end
	end
```
