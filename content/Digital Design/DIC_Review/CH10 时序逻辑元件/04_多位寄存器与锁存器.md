# 锁存器与寄存器的区别

## 核心区别：触发方式不同

|          | **锁存器 (Latch)**            | **寄存器 (Register)**        |
| -------- | -------------------------- | ------------------------- |
| **触发方式** | **电平触发** (Level-triggered) | **边沿触发** (Edge-triggered) |
| **组成**   | 门电路组合                      | 由**触发器 (Flip-Flop)** 组成   |
| **使能期间** | 输出**随输入实时变化**（透明）          | 只在时钟**边沿瞬间**采样            |
## 直观类比

- **锁存器** = 水龙头：拧开就流，关上就停
- **寄存器** = 相机快门：只在按下瞬间拍照
## 为什么实际设计中更常用寄存器？
锁存器在使能期间是"透明的"，输入的毛刺会直接传到输出，容易产生**时序问题**（glitch / hold time violation）。

> 同步数字系统设计中，几乎总是优先使用寄存器（边沿触发）而非锁存器（电平触发）。

一句话总结：**锁存器 = 电平敏感，使能期间透明；寄存器 = 边沿触发，只在时钟跳变瞬间采样。**
