# S-R锁存器(S-R Latch)

这种电路的分析，首先要知道的是，对或非门而言，如果或非门的一端输入为1，另一端输入为A的话，那么或非门的输出一定是0，但是另一种情况，或非门的一端输入为0，另一端输入为A的话，此时或非门的输出就相当于是$\bar{A}$

![[file-20260625225745692.png|630]]

然后再来看S-R Latch的功能表，当S、R都为0时，就相当于是上一节的两个反相器交叉耦合在一起(cross-coupled)，呈现的状态是存储目前锁存器中的数值。

当S/R任意一段为1的时候，会使得相应的输出置0，比如图中
R=1,S=0时，Q=0
R=0,S=1时，Q=1.
所以说S端也叫Set端，Set有效时将Q端置1，注意Set和Q两个端口在图中的位置。

当S和R都为1的时候，两个输出都强制为0，一但取消某一个输入，则两个输出重新回到互补的状态。但是如果两个输入同时取消(从1-0)，此时会产生震荡与亚稳态，这是需要注意的。

# D锁存器

S-R 锁存器有两个独立的控制端 S 和 R，用来分别控制"置位"和"复位"。但很多时候我们并不需要这么精细的控制——**我们只想把信号线上的一位数据存下来**。
1. **S-R 锁存器** → 需要分别独立控制 S 和 R 两个信号 → 适合"标志位"这种需要手动置位/复位的场景
2. 实际中还有一个更常见的需求：信号线上传来一个二进制位（data），你想把它存到某个地方 → 不需要两个输入，只需要一个 **D 输入**（你要存的值）+ 一个 **使能信号**（告诉锁存器"现在存"）
3. 所以 **D 锁存器 = 简化版的 S-R 锁存器**，把 S 和 R 合并成了一个数据输入 D

如果只想存储一位数据的话，完全可以把数据本身和数据的非接到$\bar{S}$-$\bar{R}$锁存器的两端，如下图所示:

*简陋的D锁存器*

![[JPEG图像-4281-950E-A5-0.jpeg|990]]

此时电路的行为就是，D为1的时候，Q端为1，D为0的时候，Q端为0，实现了对D的锁存。这样的涉及避免了S和R端同时起作用的尴尬局面。但是一般的D锁存器我们会给其添加一个控制端，否则的话从D输入端到Q输出端的通道一直是透明(transparent)的，所以说D锁存器的结构如下:

*真正的D锁存器*

当 G=1 时，锁存器是**透明的**（Q 跟着 D 走）；
当 G=0 时，锁存器**锁定**（反馈环路闭合，保持住当前值）。

![[file-20260626105006993.png]]

可以看到，当G为1的时候，此时控制端有效，Q输出和D输入是一致的，如*简陋的D锁存器*那样；
当G为0的时候，$\bar{S}$和$\bar{R}$端强制置1，此时控制端后接着的锁存器为*保持*状态，此时该锁存器关闭.

**亚稳态（metastability）**：

> 锁存器在一个**不稳定的中间电压**上"卡住"了，既不输出稳定的 0，也不输出稳定的 1，而是需要一段不确定的时间才能最终 settle 到某个值（也可能短暂振荡）。

# 带使能端的DFF

DFF就是一个**只在时钟边沿采样一次、其余时间一直保持**的存储单元。

![[file-20260626114701981.png|905x270]]

而为了让DFF具有使能端，我们一般不对时钟进行使能操作，否则会造成时钟偏移的问题，所以说我们采用的方法是用一个控制端EN和多路复用器来实现使能控制。当EN为1时，D端采样的为D值，当EN为0时，D端采样的是Q值，即保持当前值。
如果对状态机熟悉的话，此时我们构成的是一个激励方程为$$Q'=Q*EN$$的状态机.
