# 06 重点总结与练习题

## 1. 易混概念总结

| 概念 | 关键点 |
|---|---|
| ROM | 正常工作以读为主，内容通常预先写入或慢速改写 |
| RAM | 可随机读写，通常掉电丢失 |
| SRAM | 静态保存，不刷新，快但面积大 |
| SSRAM | 同步 SRAM，使用时钟控制读写 |
| DRAM | 电容存储，需要刷新，密度高 |
| SDRAM | 同步 DRAM，命令和数据与时钟同步 |
| LUT | FPGA 中实现组合逻辑的小型查找表，本质类似小 ROM |
| CLB | FPGA 的可配置逻辑块，包含 LUT、触发器等 |
| 地址位宽 | 决定可寻址单元数量 |
| 数据位宽 | 决定每次访问读/写多少 bit |
| 总容量 | 地址深度 x 数据位宽 |

## 1.1 存储单元容量与易用性对比

> 核心考点：**同样容量下谁更大？谁更难驱动？**

| 对比项 | SRAM | DRAM |
|---|---|---|
| 每 bit 单元 | 6 个晶体管（交叉耦合反相器 + 读写访问管） | 1 个晶体管 + 1 个电容（1T1C） |
| **同容量物理面积** | **更大**（晶体管多，密度低） | **更小**（结构简单，密度高） |
| **同容量成本** | **更高** | **更低** |
| **驱动难度** | **更简单**：上电即可保持数据，无需刷新；读写控制信号简单 | **更困难**：需要刷新控制器、预充电、感放器、读后恢复等额外电路 |
| 刷新需求 | 不需要 | 需要周期性刷新（通常每 64 ms 全部刷新一轮） |
| 典型用途 | 高速缓存（Cache）、片上 SRAM、寄存器文件 | 主存（Main Memory）、大容量存储 |

**一句话记忆**：
- SRAM → 快、贵、大、简单（上电即用）
- DRAM → 慢、便宜、小、复杂（需要刷新电路）

**对应填空题考点**（常见考法）：
- "相同容量下，SRAM 比 DRAM 物理面积更 **大**"
- "使 DRAM 正常工作比 SRAM 更 **困难**（需要刷新、预充电等控制）"

## 3. 计算题

1. 某 ROM 有 15 根地址线和 8 根数据线，求其规格和总容量。
2. 一个 `256K x 16` RAM 的总容量是多少 bit？是多少 Byte？
3. 要设计 `64K x 32` 存储器，已有 `16K x 8` 芯片，至少需要多少片？说明如何扩展。
4. 一个存储器总容量为 `128 KB`，每个地址存储 `16 bit`，需要多少根地址线？
5. 一个 FPGA 中的 6 输入 LUT 能实现任意几输入组合逻辑函数？需要多少个配置位？
6. 某系统需要存储 4096 个 12-bit 数据。若使用 `1K x 4` RAM 芯片，需要多少片？

## 4. 填空题答案

1. `n`，`b`，`2^n x b`
2. `1024`，`8192`
3. 锁存器或交叉耦合反相器
4. 电容电荷
5. 时钟
6. LUT
7. `k`，`2^k`
8. 共用
9. 译码器
10. 输出使能，写使能
11. 大
12. 困难，刷新电路（周期性刷新、预充电、感放器等额外控制逻辑）

## 5. 计算题答案

1. `2^15 x 8 = 32K x 8`，总容量 `32 KB`。
2. `256K x 16 bit = 2^18 x 16 = 2^22 bit = 4 Mbit = 512 KB`。
3. 深度扩展 `64K/16K = 4` 倍，位宽扩展 `32/8 = 4` 倍，总片数 `4 x 4 = 16` 片。低位地址接所有芯片，高位地址译码选择 4 组，每组 4 片并联扩展位宽。
4. `128 KB = 2^17 Byte = 2^20 bit`。每地址 16 bit，所以深度 `2^20 / 2^4 = 2^16`，需要 16 根地址线。
5. 可实现任意 6 输入组合逻辑函数，需要 `2^6 = 64` 个配置位。
6. 目标规格为 `4096 x 12 = 4K x 12`。深度扩展 `4K/1K = 4`，位宽扩展 `12/4 = 3`，总片数 `4 x 3 = 12` 片。
