# 02 ROM 只读存储器

## 1. ROM 的基本结构

ROM 是只读存储器(Read-Only Memory)，正常工作时通过地址输入选择一个存储位置，并在数据输出端给出该地址对应的数据。

典型 ROM 可表示为：

```text
2^n x b ROM
```

其接口包括：

- 地址输入：`A0 ~ A(n-1)`，共 `n` 位。
- 数据输出：`D0 ~ D(b-1)`，共 `b` 位。
- 片选/输出使能等控制信号：不同芯片可能使用 `CS`、`OE` 等。

## 2. ROM 的内部思想

ROM 的基本思想可以理解为"地址译码器 + 固定连接矩阵"：

![[file-20260702104834277.png|649]]

1. 地址输入送入译码器。
2. 译码器选中某一条字线。
3. 被选中字线通过预先编程好的连接关系，在位线上形成对应输出。

如果某一地址对应的数据位为 1，则该行与对应列之间可以存在有效连接；如果为 0，则没有连接或采用相反逻辑实现。实际芯片可能使用不同工艺和逻辑结构，但抽象模型都是"地址选字，矩阵给出数据"。

## 3. ROM 的类型

常见 ROM 类型：

- Mask ROM：制造时写入内容，用户不能修改。

![[file-20260702105828876.png|586]]

- PROM：用户一次性编程。

![[file-20260702105849710.png|677]]

引入导电熔丝实现编程功能

- EPROM：可擦除可编程 ROM，通常通过紫外线擦除。

![[file-20260702110024223.png|775]]
 
- EEPROM：电可擦除可编程 ROM，可以按字节或块电擦除。

- Flash：EEPROM 的一种扩展形式，通常按块擦除，密度高，常用于固件、配置存储和大容量非易失存储。

EPROM/EEPROM 常使用浮栅 MOS 管保存信息。浮栅中是否存储电荷会影响晶体管阈值电压，从而改变该单元读出时表现出的逻辑值。

## 4. ROM 与 RAM 的核心区别

ROM 和 RAM 在 cell 级别的核心区别在于：**ROM 的 cell 中没有独立存储元件，数据以固定连接的形式存在；RAM 的 cell 有独立的 memory unit（如 SRAM 的锁存器或 DRAM 的电容），通过 MOS 访问管控制与 bit line 的通断，从而实现读写访问。**

- ROM 的 connect device（可以是二极管、MOS 管等）本身就是存储——有连接代表 1，无连接代表 0，制造后固定不变。
- RAM 的 memory unit 能独立维持状态，需要 MOS 访问管作为开关：字线激活时导通，使 memory unit 与 bit line 连通；未选中时隔离，避免干扰共享同一 bit line 的其他 cell。

![[file-20260702105340331.png|701]]

| 项目 | ROM | RAM |
|---|---|---|
| 正常使用时是否可写 | 一般不可写或写入很慢 | 可快速读写 |
| 典型用途 | 固件、查找表、固定逻辑、配置数据 | 运算中间数据、缓存、寄存数据 |
| 掉电是否保持 | 通常保持 | 多数普通 RAM 掉电丢失 |
| 访问方式 | 地址读出数据 | 地址读出或写入数据 |
