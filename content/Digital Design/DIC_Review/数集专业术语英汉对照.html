复习导读

先搭框架：从数制编码、逻辑门、组合逻辑到时序逻辑，按“表示数据 → 处理数据 → 存储状态 → 构成数字集成系统”的顺序理解。
再抓考点：重点关注补码、卡诺图、触发器时序参数、FSM、存储器结构、可编程逻辑和 Verilog 赋值规则。
最后查细节：把英文术语、中文翻译和常见题型绑定记忆，避免只背中文概念却看不懂英文题干。

核心知识框架

  1. 数制与编码：掌握二进制、补码、BCD、格雷码和校验码，重点是范围、转换和溢出判断。
  2. 逻辑代数：会用真值表、表达式、卡诺图和德摩根定律完成化简，并理解毛刺产生原因。
  3. 组合逻辑：熟悉译码器、编码器、MUX、加法器、比较器等模块的输入输出关系。
  4. 时序逻辑：抓住锁存器、触发器、时钟、建立保持时间和亚稳态这些核心概念。
  5. 状态机与系统设计：能区分 Moore/Mealy，理解状态编码、次态逻辑、输出逻辑和关键路径。
  6. Verilog 与可编程逻辑：把 HDL 语法和硬件含义对应起来，尤其注意阻塞/非阻塞赋值、wire/reg、综合与仿真的差异。

考试高频核心词速记

最常考概念

  1. Setup Time：建立时间，时钟沿到来前数据必须稳定。
  2. Hold Time：保持时间，时钟沿之后数据仍需稳定。
  3. Propagation Delay：传播延迟，输入变化到输出响应的时间。
  4. Metastability：亚稳态，触发器进入不确定状态。
  5. Critical Path：关键路径，决定系统最高时钟频率。

Verilog 必背关键词

  • module / endmodule：模块声明与结束
  • input / output / inout：端口方向
  • wire / reg / parameter：信号与参数类型
  • assign / always / initial：常用建模语句
  • posedge / negedge：时钟边沿触发
  • blocking (=) / nonblocking (<=)：阻塞与非阻塞赋值

易混淆术语辨析

Latch vs Flip-Flop

Latch 是电平触发，使能有效时输出会随输入变化；Flip-Flop 是边沿触发，只在指定时钟沿采样并更新。

Combinational vs Sequential

组合逻辑的输出只由当前输入决定；时序逻辑还依赖历史状态，因此需要存储单元和时钟/反馈机制。

Moore vs Mealy

Moore 输出只取决于当前状态，通常更稳定；Mealy 输出同时取决于状态和输入，响应快但更容易受输入毛刺影响。

SRAM vs DRAM

SRAM 用触发器存储，速度快、不需刷新、成本高；DRAM 用电容存储，容量大、成本低，但必须周期性刷新。

Blocking vs Nonblocking

= 按语句顺序立即赋值，常用于组合逻辑；<= 在时钟事件后统一更新，常用于时序逻辑。

Synchronous vs Asynchronous Reset

同步复位只在时钟沿生效，时序更可控；异步复位无需等待时钟即可生效，响应更快但释放时要注意同步。
