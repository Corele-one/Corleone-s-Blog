# Module
Verilog中最重要的概念就是模块，在有了模块这个概念之后我们就能够更好地进行层次化的设计，如下图所示：

![[file-20260614223956286.png|831]]

在 Verilog 中，信号、常量和其他定义的适⽤范围（ scope ) 对每个模块来说都是**局部性质**的；只有通过使⽤被声明的输⼊和输出信号，才能让它们的值在模块之间进⾏传递。
## Verilog模块声明的基本语法
它以关键字 module开头，跟着的是模块名称的标识符和模块输⼈输岀端⼝的标识符列表。输⼊输出端⼝（ input and output ports ) 是该模块与其他模块互相沟通的信号，可以把它们想象成连线，因为它们正是模块通常要实现的东西。

![[file-20260614224550405.png|534x333]]

声明模块的时候也可以采用ANSI的风格声明，这种声明的好处就是声明的时候可以同时声明端口名、信号方向和可选的取值范围

![[file-20260614225324391.png|800]]

如果没有提及端口的类型的话，**默认为1位的wire**

## Verilog中的两类信号
### 网格(Net)
⽹格（net ) ⼤致对应于物理电路中的连线，在 Verilog 结构模型中提供模块与其他元件之间的连通性。在 Verilog 模块的输⼊/输出端⼝列表中的信号，常常就是⽹格。
最常见的网格类型是wire，除wire之外还有supply0，supply1等网络类型可以被认为是连接到电源轨上的永久性连线。

![[file-20260614225946370.png|316]]

Verilog ⽹格声明（net declaration ) 的语法类似于输⼈ / 输出声明。对于向量⽹格(Vector)，则需在标识符列表的前⾯指定它的“界”。
![[file-20260614231019002.png|814]]

### 变量(Variable)

是在 Verilog 程序执⾏期间⽤于存储数值的，它们并没有实际的物理意义，仅用在**过程编码**中。最常用的两种变量类型是reg和integer变量

# 逻辑操作符和表达式

**逻辑操作注意和逐位布尔操作做区分**，逐位布尔操作中，取非为~,在逻辑操作中，取非为!

![[file-20260614234424137.png|811]]

逻辑相等和不相等操作符是对操作数⼀位⼀位地进⾏⽐较的,仅当对应的位都相等时才是相等的
## 条件操作符

A = B ? C : D;
如果B为真，那么A=C，如果B为假，那么A=D
并且，条件操作符是可以嵌套使用的
