# 02 时序图与时序计算

Figure 13-1 展示了本章最核心的时序关系：时钟边沿触发源寄存器输出变化，数据经过组合逻辑到达目的寄存器，目的寄存器必须在下一次采样边沿前后满足建立时间和保持时间。

## 基本时间参数

![[file-20260702095555120.png]]

| 参数                   | 含义                | 用途       |
| -------------------- | ----------------- | -------- |
| `Tclk`               | 时钟周期              | 决定系统频率   |
| `tCQ(max)` / `tffpd` | 时钟到寄存器输出稳定的最大延迟   | setup 分析 |
| `tCQ(min)` / `tffcd` | 时钟到寄存器输出开始变化的最小延迟 | hold 分析  |
| `tcomb(max)`         | 组合逻辑最大传播延迟        | setup 分析 |
| `tcomb(min)`         | 组合逻辑最小污染延迟        | hold 分析  |
| `tsetup`             | 采样边沿前输入必须提前稳定的时间  | setup 分析 |
| `thold`              | 采样边沿后输入必须继续稳定的时间  | hold 分析  |

## 建立时间约束

setup 检查看的是“数据是否来得及到达”，因此使用最大延迟，其中$t_{com}$(组合逻辑延时)取最大值，表示新数据稳定所需要的时间。

![[file-20260702100922047.png]]

上图中的建立时间余量为0，因为当经过$t_{pd}$/$t_{comb}$之后，刚好满足$t_{setup}$

无时钟偏斜时：

```text
Tclk >= tCQ(max) + tcomb(max) + tsetup
```

建立时间余量：

```text
setup margin = Tclk - tCQ(max) - tcomb(max) - tsetup
```

最大频率：

```text
fmax = 1 / Tclk(min)
```

若 setup margin 为负，说明该路径太慢。常见修复方式：

- 降低时钟频率。
- 优化组合逻辑。
- 增加流水线，把长组合路径拆短。
- 选择更快的寄存器或逻辑单元。

## 保持时间约束

![[file-20260702101545237.png|986]]

hold 检查看的是“新数据是否太早到达”，因此使用最小延迟。其中$t_{com}$(组合逻辑延时)取最小值，表示新数据开始变化所需要的时间。

无时钟偏斜时：

```text
tCQ(min) + tcomb(min) >= thold
```

保持时间余量：

```text
hold margin = tCQ(min) + tcomb(min) - thold
```

若 hold margin 为负，说明短路径太快。常见修复方式：

- 在短数据路径上插入 buffer 或延迟单元。
- 调整时钟树，让相关 skew 更有利。
- 避免相邻寄存器之间存在过短的直连路径。

## 考虑时钟偏斜

![[file-20260702101642800.png|698x306]]

定义：

```text
tskew = 目的寄存器时钟到达时间 - 源寄存器时钟到达时间
```

若 `tskew > 0`，目的寄存器时钟比源寄存器晚到；若 `tskew < 0`，目的寄存器时钟比源寄存器早到。

setup 约束：

```text
Tclk >= tCQ(max) + tcomb(max) + tsetup - tskew
setup margin = Tclk - tCQ(max) - tcomb(max) - tsetup + tskew
```

hold 约束：
以$t_{skew}>0$为例，如果$t_{skew}>0$说明时钟到达目的寄存器的时间要比无时钟偏移的情况晚了$t_{skew}$，而这部分$t_{skew}$就会叠加到保持时间上
```text
tCQ(min) + tcomb(min) >= thold + tskew
hold margin = tCQ(min) + tcomb(min) - thold - tskew
```

结论：

- 正时钟偏斜通常放松 setup，但恶化 hold。
- 负时钟偏斜通常恶化 setup，但放松 hold。
- 真实设计必须同时检查 setup 和 hold，不能只看最大频率。

## 公式汇总

| 项目 | 公式 |
|---|---|
| 无 skew setup | `Tclk >= tCQ(max) + tcomb(max) + tsetup` |
| 无 skew setup margin | `Tclk - tCQ(max) - tcomb(max) - tsetup` |
| 无 skew hold | `tCQ(min) + tcomb(min) >= thold` |
| 无 skew hold margin | `tCQ(min) + tcomb(min) - thold` |
| 有 skew setup | `Tclk >= tCQ(max) + tcomb(max) + tsetup - tskew` |
| 有 skew hold | `tCQ(min) + tcomb(min) >= thold + tskew` |
