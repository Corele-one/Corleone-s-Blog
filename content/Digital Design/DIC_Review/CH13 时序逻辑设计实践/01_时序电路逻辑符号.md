# 01 时序电路逻辑符号

时序电路的逻辑符号用于表达“何时采样、何时更新、是否复位、是否使能”等行为。相比组合逻辑，时序逻辑多了存储元件，因此输出不仅由当前输入决定，还与过去状态有关。

## 常见符号

![[file-20260702095431952.png|800]]
`generate by Gemini`

| 符号/标记                 | 含义       | 设计含义                     |
| --------------------- | -------- | ------------------------ |
| `D`                   | 数据输入     | 在有效时钟边沿前后必须满足 setup/hold |
| `Q`                   | 寄存器输出    | 在时钟有效边沿后经过 `tCQ` 才稳定     |
| `CLK` 端小三角 `>`        | 边沿触发     | 表示由时钟边沿采样，而不是电平透明        |
| 时钟端小圆圈                | 下降沿触发    | 没有圆圈通常表示上升沿触发            |
| 输入/输出端小圆圈             | 低有效信号    | 例如低有效复位、低有效使能            |
| `EN` / `CE`           | 时钟使能     | 推荐使用寄存器内部 clock enable   |
| `RST` / `CLR` / `PRE` | 复位/清零/置位 | 要区分同步复位和异步复位             |

## 组合逻辑与时序逻辑

组合逻辑没有记忆功能：

```text
当前输入 -> 组合逻辑 -> 当前输出
```

时序逻辑含有触发器或锁存器：

```text
当前输入 + 当前状态 -> 组合逻辑 -> 下一状态

下一状态 --时钟边沿--> 当前状态
```

同步时序系统通常可以抽象为：

```text
寄存器组 -> 组合逻辑 -> 寄存器组
       ^              |
       |              v
      同一个系统时钟控制采样
```



## 学习要点

- 看到触发器符号时，先判断触发边沿、复位方式、使能方式。
- 对同步设计，所有状态更新应由同一时钟域的有效边沿控制。
- 不要把普通组合逻辑输出随意当作时钟。
- 时钟使能和门控时钟不是同一件事。FPGA 中通常优先使用 `CE`，ASIC 中门控时钟一般使用标准 ICG 单元。
