# 07 练习题

按大纲中“需要掌握”的内容设计计算题、填空题、判断题和简答题。

## 一、计算题

### 题 1：无时钟偏斜的最大频率

某同步路径中，`tCQ(max)=0.8 ns`，`tcomb(max)=5.6 ns`，目的触发器 `tsetup=0.7 ns`。忽略时钟偏斜。

1. 最小时钟周期是多少？
2. 最大时钟频率是多少？

解：

```text
Tclk(min) = 0.8 + 5.6 + 0.7 = 7.1 ns
fmax = 1 / 7.1 ns = 140.8 MHz
```

答：最小时钟周期为 `7.1 ns`，最大频率约为 `140.8 MHz`。

### 题 2：setup margin

某路径 `Tclk=10 ns`，`tCQ(max)=1.2 ns`，`tcomb(max)=6.4 ns`，`tsetup=1.0 ns`。求 setup margin，并判断是否满足建立时间。

解：

```text
setup margin = 10 - 1.2 - 6.4 - 1.0 = 1.4 ns
```

答：建立时间余量为 `1.4 ns`，满足 setup。

### 题 3：hold margin

某路径 `tCQ(min)=0.3 ns`，`tcomb(min)=0.6 ns`，目的触发器 `thold=0.8 ns`。忽略时钟偏斜。求 hold margin。

解：

```text
hold margin = 0.3 + 0.6 - 0.8 = 0.1 ns
```

答：保持时间余量为 `0.1 ns`，满足 hold。

### 题 4：考虑正时钟偏斜的 setup

某路径 `tCQ(max)=0.6 ns`，`tcomb(max)=4.0 ns`，`tsetup=0.5 ns`，`Tclk=5.0 ns`。目的寄存器时钟比源寄存器晚到 `0.4 ns`。求 setup margin。

解：

```text
tskew = +0.4 ns
setup margin = 5.0 - 0.6 - 4.0 - 0.5 + 0.4
             = 0.3 ns
```

答：setup margin 为 `0.3 ns`，满足建立时间。

### 题 5：正时钟偏斜对 hold 的影响

沿用题 4 的时钟偏斜，若短路径参数为 `tCQ(min)=0.2 ns`，`tcomb(min)=0.3 ns`，`thold=0.2 ns`，求 hold margin。

解：

```text
hold margin = 0.2 + 0.3 - 0.2 - 0.4
            = -0.1 ns
```

答：hold margin 为 `-0.1 ns`，违反保持时间。

### 题 6：插入延迟修复 hold

某短路径 hold margin 为 `-0.25 ns`。若在数据路径插入 buffer，每个 buffer 的最小延迟为 `0.10 ns`，至少需要插入几个 buffer？

解：

```text
ceil(0.25 / 0.10) = 3
```

答：至少插入 `3` 个 buffer。

## 三、判断题

1. 只要 setup 满足，hold 就一定满足。  
   答：错。setup 看最大延迟，hold 看最小延迟。

2. 正时钟偏斜一定是好事。  
   答：错。它可能改善 setup，但会恶化 hold。

3. 时钟树的目标是让所有触发器的时钟绝对延迟为 0。  
   答：错。目标是让时钟到达差异受控，减小 skew。

4. FPGA 中建议优先使用触发器自带 clock enable，而不是自己用 LUT 生成门控时钟。  
   答：对。

5. 两级同步器可以完全消除亚稳态。  
   答：错。它只能降低亚稳态传播到后级系统的概率。

6. 多比特异步总线逐位加两级同步器后就一定可靠。  
   答：错。不同位可能在不同周期稳定，形成错误数据。

## 四、简答题

### 题 1：为什么不能随意把组合逻辑输出当作时钟？

组合逻辑输出可能有毛刺，且传播延迟、上升下降时间、skew 都不可控。若用作时钟，触发器可能被窄脉冲误触发，STA 和时钟树工具也难以正确建模。

### 题 2：数据通路和控制器的区别是什么？

数据通路负责保存、选择、运算和传输数据；控制器负责根据状态和输入条件产生控制信号，决定数据通路在每个周期执行什么操作。

### 题 3：为什么异步输入要先进同步器再进入同步系统？

异步输入可能在接收时钟采样边沿附近变化，导致触发器亚稳态。同步器给亚稳态一个或多个周期恢复，并保证同步系统只看到接收时钟域内的稳定信号。

### 题 4：什么时候使用异步 FIFO？

当发送方和接收方属于不同且持续运行的时钟域，并且需要传输多比特数据流时，应使用异步 FIFO。
