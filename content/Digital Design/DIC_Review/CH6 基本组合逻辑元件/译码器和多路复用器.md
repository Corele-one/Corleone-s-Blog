# 译码(decode)

译码的作用是，根据期望的输入值(sel)来激活(output对应不同值)一个或多个其他电路。

![[file-20260619001056040.png|899]]

decoder是任何一种多输入多输出的组合逻辑电路，可以将**输入编码字==映射==为输出编码字**。

一个n位二进制代码，有时会被截断以表达少于$2^n$个值，比如说有5个端口需要选择，就可以用3位的选择值，用二进制编码001-101选择端口1-5

## 用小译码器构成大型译码器

用cascading(串联)的方法来设计具有多输入的译码器，如图为用74x138(3-8译码器)设计的5-32译码器

![[file-20260619111540236.png|500]]

### 级联原理

>其中第二级的译码器组共用低三位的地址，高两位地址连接在第一级的“选择”译码器上，根据第一级的译码器来选择第二级中对应的译码器，这样就通过译码器的级联实现较多输入的译码器。

核心思想是利用 74x138 的**使能端（G1, G2A, G2B）** 来控制译码器的激活，从而实现分层选择。

**第一级（选择译码器）：**
- 输入：5位地址的高两位 D4、D3
- 连接：D4、D3 → A、B（地址端）；G1 → EN（总使能）；G2A、G2B → GND
- 输出：Y0–Y7 中每次只有一个输出为低电平（有效），分别对应 D4D3 的四种组合（00、01、10、11）
- 作用：从四个第二级译码器中**选出一个**使其工作

**第二级（四组 3-8 译码器）：**
- 输入：四组译码器共享低三位地址 D2、D1、D0 → A、B、C
- 使能控制：每个译码器的 G2A 分别接第一级的一个输出（Y0→第1组，Y1→第2组，Y2→第3组，Y3→第4组）；G1 → EN；G2B → GND
- 输出：每组产生 8 个输出（DISP0_0 ~ DISP3_7），共 32 个

**工作流程：**
1. 当 D4D3 = 00 时，第一级 Y0 输出低电平 → 仅第1组译码器的 G2A 有效 → 第1组根据 D2D1D0 译出 DISP0_0 ~ DISP0_7 中的一个
2. 当 D4D3 = 01 时，第一级 Y1 输出低电平 → 仅第2组译码器被激活 → 译出 DISP1_0 ~ DISP1_7 中的一个
3. D4D3 = 10、11 同理，分别激活第3、第4组

> **关键点：** 74x138 的 G2A 是**低电平有效**的使能输入，这意味着只有当 G2A = 0 时译码器才工作。第一级译码器利用这一特性——其输出中只有一个为低，从而恰好使能第二级中对应的一组译码器，其余三组因 G2A = 1 而被禁用，输出全部为高。

这样，高位地址（D4D3）通过第一级译码器决定了”哪一组”工作，低位地址（D2D1D0）决定了组内”哪一个”输出有效，从而实现了 5-32 译码。


## 用Verilog实现译码器


![[file-20260619001739711.png|743]]

### 结构化描述
```verilog
module decode2_4(A0,A1,EN,Y0,Y1,Y2,Y3);
	input A0,A1,EN;
	output Y0,Y1,Y2,Y3;
	wire not_A0,not_A1;
	not u1(not_A0,A0);
	not u2(not_A1,A1);
	and u3(Y0,not_A0,not_A1,EN);
	and u4(Y1,A0,not_A1,EN);
	and u5(Y2,not_A0,A1,EN);
	and u6(Y3,A0,A1,EN);
endmodule
```

### 数据流描述

```verilog
module decode2_4(A0,A1,EN,Y0,Y1,Y2,Y3);
	input A0,A1,EN;
	output Y0,Y1,Y2,Y3;
	assign Y0 = EN?({A1,A0}==2'b00):0;
	assign Y1 = EN?({A1,A0}==2'b01):0;
	assign Y2 = EN?({A1,A0}==2'b10):0;
	assign Y3 = EN?({A1,A0}==2'b11):0;
	//这四条连续赋值语句并行执行
endmodule
```


### 行为化描述

![[file-20260619113808906.png|727]]

**注意过程块里，输出端口定义为reg类型**

```verilog
module decode2_4(A0,A1,EN,Y0,Y1,Y2,Y3);
	input A0,A1,EN;
	output reg Y0,Y1,Y2,Y3;//输出端口定义为reg类型
	always @(A0,A1,EN) begin
		if(EN) begin
			case({A1,A0})
				2'b00:{Y3,Y2,Y1,Y0} = 4'b0001;
				2'b01:{Y3,Y2,Y1,Y0} = 4'b0010;
				2'b10:{Y3,Y2,Y1,Y0} = 4'b0100;
				2'b00:{Y3,Y2,Y1,Y0} = 4'b1000;
				default:{Y3,Y2,Y1,Y0} = 4'b0000;
				//不管条件有没有全覆盖，都要加default
			endcase
		end
		else begin
			{Y3,Y2,Y1,Y0} = 4'b0000;
		end
	end
endmodule
```

另一种2-4译码器的行为级描述，这种描述使用了for语句来做更本质的行为模拟，而非上一种写法中仅仅是对真值表的模拟

```verilog
module decode2_4(A0,A1,EN,Y0,Y1,Y2,Y3);
	input A0,A1,EN;
	output reg Y0,Y1,Y2,Y3;//输出端口定义为reg类型
	reg [3:0] IY;
	integer i;
	always @(A0,A1,EN) begin
		IY = 4'b0000;
		if(EN==1) bein
			for(i=0;i<=3;i=i+1) begin
				if(i=={A1,A0}) IY[i]=1;
			end//循环产生内部变量IY
		end
		{Y3,Y2,Y1,Y0} = IY;//内部变量复制给输出
	end
endmodule
```

还有一种更简练的，直接把{A1,A0}作为索引

```verilog
module decode2_4(A0,A1,EN,Y0,Y1,Y2,Y3);
	input A0,A1,EN;
	output reg Y0,Y1,Y2,Y3;//输出端口定义为reg类型
	reg [3:0] IY;
	always @(A0,A1,EN) begin
		IY = 4'b0000;
		if(EN==1) bein
			IY[{A1,A0}] = 1;//简单粗暴
		end
		{Y3,Y2,Y1,Y0} = IY;//内部变量复制给输出
	end
endmodule
```

## 定制译码器

### 七段译码器的verilog程序


![[file-20260619121015352.png|725]]

BCD码：Binary-coded-Decimal，4位BCD码，用0000-1001编码0-10，其余为无关项

```verilog
module segdec( DIG , EN , SEGA , SEGB , SEGC , SEGD , SEGE , SEGF , SEGG );
    input [3:0] DIG ;//4位BCD码数据输入端
    input EN ;
    output reg SEGA , SEGB , SEGC , SEGD , SEGE , SEGF , SEGG ;
    reg [1:7] SEGS ;//串接和辅助变量

    always @(DIG or EN or SEGS) begin
        if (EN)
            case (DIG) //Segment patterns abcdefg
	            //注意是高有效还是低有效的段码
                4'd0: SEGS = 7'b1111110; //0
                4'd1: SEGS = 7'b0110000; //1
                4'd2: SEGS = 7'b1101101; //2
                4'd3: SEGS = 7'b1111001; //3
                4'd4: SEGS = 7'b0110011; //4
                4'd5: SEGS = 7'b1011011; //5
                4'd6: SEGS = 7'b0011111; //6( no ' tail ')
                4'd7: SEGS = 7'b1111000; //7
                4'd8: SEGS = 7'b1111111; //8
                4'd9: SEGS = 7'b1111011; //9( no ' tail ')
                default SEGS = 7'bxxxxxxx;
            endcase
        else 
            SEGS = 7'b0000000;

	{ SEGA , SEGB , SEGC , SEGD , SEGE , SEGF , SEGG } = SEGS;
    end
endmodule
```

## 二进制编码器(encoder)

之前我们实现过2-4的译码器，译码器被定义为任意多输入多输出的组合逻辑电路，基于这样的定义，我们可以反过来，把实现与二进制译码器反向的变换电路称为编码器。

![[file-20260619145833567.png|682]]

和译码器相比较来看，因为译码器输出独热码，所以输出为一组与门。又因为编码器的输出为n位二进制编码，输出逻辑表达式为与或逻辑。

# 多路复用器(选择)

从n个数据源中选一个数据，连到输出端。也提供一个可选的使能输入EN

![[file-20260619151633913.png|340x211]]

因为2-4译码器输出为独热码(n中取1码)，其实也可以看做是一个**多路的选择码**，因为其和MUX都实现了选择功能，所以MUX可以当作一个二进制译码器控制的单个开关的集合。译码器的输出与各个开关相连，每个开关对应一个编号的数据源。由译码器来选通数据。

![[file-20260619152434723.png|562]]

至于译码器怎么选通数据的，一般是采用下图中的传输门(Transiton Gate 结构)
最左边的结构为非门，产生互补的信号接到传输门两端，传输门在相应的信号下选通数据通路

![[file-20260619152730771.png|550]]

![[file-20260619153102681.png|949]]

当然，最简单粗暴的方式是直接把译码器输出的独热编码和数据AND在一起(选择)，然后用一个超级多输入的或门来输出

![[file-20260619153338476.png|5861]]

多路复用器的数据选择端的位数s和数据通路数量n的关系为
>$s≥\log_{2}(n)$

## Verilog实现MUX

### 数据流描述
采用条件操作符来提供所需的功能
```verilog
module mux2in8(EN_L,S,D0,D1,Y);
	input [7:0] D0,D1;
	input  S;
	input EN_L;
	output [7:0] Y;
	assign Y=(~EN_L==1'b0)?8'b0:(S==1'b0?D0:(S==1'b1?D1:8'bx));
endmodule
```

### 行为级描述

```verilog
module mux2in8(EN_L,S,D0,D1,Y);
	input [7:0] D0,D1;
	input  S;
	input EN_L;
	output reg [7:0] Y;
	always @(*) begin
		if(~EN_L==1'b0) Y=8'b0;
		else if(S==1'b0) Y=D0;
		else if(S==1'b1) Y=D1;
		else Y=8'bx;
	end
endmodule
```

多输入的话就用case语句
4输入8位MUX
```verilog
module mux4in8(EN_L,S,A,B,C,D,Y);
	input EN_L;
	input [1:0] S;
	input [7:0] A,B,C,D;
	output reg [7:0] Y;
	always@(*) begin
		if(~EN_L==1'b0) Y=8'b0;
		else begin
			case(S)
				2'b00:Y=A;
				2'b01:Y=B;
				2'b10:Y=C;
				2'b11:Y=D;
				default:Y=8'bx;
			endcase
		end
	end
endmodule
```
