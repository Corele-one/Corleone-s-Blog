# 关于无效状态的处理

[[用状态表设计状态机]]

## 为什么会出现无效状态？

在状态编码时，若状态机有 $s$ 个有效状态，则需要用 $\lceil \log_2 s \rceil$ 个触发器（状态变量）来编码。然而 $n$ 个触发器最多可以编码 $2^n$ 个状态，当 $2^n > s$ 时，就会出现**无效状态**（unused/invalid states）。

以上面的例子为例：该状态机有 5 个有效状态（INIT, A0, A1, OK0, OK1），需要 $\lceil \log_2 5 \rceil = 3$ 个触发器。而 3 个触发器可以编码 $2^3 = 8$ 个状态，因此会有 $8 - 5 = 3$ 个无效状态。

例如采用"最简单的赋值"方案：

| 状态名 | Q1 Q2 Q3 |
|--------|----------|
| INIT   | 000      |
| A0     | 001      |
| A1     | 010      |
| OK0    | 011      |
| OK1    | 100      |
| **无效** | 101    |
| **无效** | 110    |
| **无效** | 111    |

正常工作时，状态机只会在 000~100 之间流转，不会进入 101、110、111。但实际电路中，由于**硬件故障、意外输入信号或设计错误**，状态机有可能跳入这些无效状态。因此需要决定：**无效状态的次态和输出该如何处理？**

## 两种处理方法

### 最小风险法（Minimum Risk Method）

**核心思想**：假设状态机**可能会**由于某种原因进入无效状态，因此应为每一种无效状态明确规定次态，使得对于任何输入组合，无效状态都能进入"初始"状态、"空闲"状态或其他一些"安全"状态。

**优点**：
- 系统具有自恢复能力（self-recovery），即使因干扰进入无效状态也能自动回到正常工作状态
- 电路行为完全可预测
- 对于当前实现技术中要求激励逻辑成本低的情况，优先选择此方法更合理

**缺点**：
- 需要为无效状态的每一个输入组合都指定次态，增加了设计工作量
- 激励逻辑可能稍复杂

**以上面的例子说明**：采用最小风险法时，对 3 个无效状态（101, 110, 111），需要在状态表的次态列中**显式指定**每个无效状态在 AB=00, 01, 11, 10 各输入下的次态。例如可以让所有无效状态在任何输入下都跳回 INIT（000），即回到初始状态重新开始：

```verilog
无效状态 101: AB=00→INIT, AB=01→INIT, AB=11→INIT, AB=10→INIT, Z=0
无效状态 110: AB=00→INIT, AB=01→INIT, AB=11→INIT, AB=10→INIT, Z=0
无效状态 111: AB=00→INIT, AB=01→INIT, AB=11→INIT, AB=10→INIT, Z=0
```

这样无论什么原因导致进入了无效状态，下一个时钟周期一定回到 INIT，系统重新正常运行。

### 最小成本法（Minimum Cost Method）

**核心思想**：假设机器**永远不会**进入无效状态。因此，在转移表和激励表中，无效状态的次态可标为**"无关"项（don't care, ×）**。

**优点**：
- 在大多数情况下，可以**简化激励逻辑**（因为卡诺图中可以利用无关项进行更大的圈组）
- 减少所需的逻辑门数量

**缺点**：
- 如果机器一旦进入了无效状态，那么状态机的行为就是**不可把握的**（unpredictable）
- 系统没有自恢复能力

**以上面的例子说明**：采用最小成本法时，3 个无效状态（101, 110, 111）的次态全部标记为无关项：

```verilog
无效状态 101: AB=00→×××, AB=01→×××, AB=11→×××, AB=10→×××, Z=×
无效状态 110: AB=00→×××, AB=01→×××, AB=11→×××, AB=10→×××, Z=×
无效状态 111: AB=00→×××, AB=01→×××, AB=11→×××, AB=10→×××, Z=×
```

在后续化简激励函数的卡诺图中，这些无关项可以根据需要取 0 或 1，从而使圈组更大、表达式更简。

## 对比总结

|              | 最小风险法                 | 最小成本法                  |
| ------------ | --------------------- | ---------------------- |
| **对无效状态的假设** | 可能会进入                 | 永远不会进入                 |
| **次态处理**     | 显式指定跳转到安全状态           | 标记为无关项（don't care）     |
| **输出处理**     | 通常设为安全值（如 0）          | 标记为无关项                 |
| **自恢复能力**    | 有（自动回到正常状态）           | 无（行为不可预测）              |
| **激励逻辑复杂度**  | 较高                    | 较低（可利用无关项化简）           |
| **适用场景**     | 高可靠性要求；Verilog 设计中较方便 | 追求最小面积/成本；包含大量状态机实例的电路 |

> [!tip] 设计建议
> 对于当前实现技术中要求激励逻辑成本低的情况，**优先选择最小风险方法**更合理。它可能还可以减少工程设计时间（例如，因为 Verilog 不能提供一种便利的方法以在激励逻辑中指定"无关项"）。真正迫使我们选择最小成本法的唯一原因是：我们是否正在设计一个**包含大量状态机物理实例的电路**。
