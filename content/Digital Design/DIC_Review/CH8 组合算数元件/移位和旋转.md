# 用Verilog实现桶形移位器

## 循环左移桶形移位器-行为级描述

```verilog
//把移位过程分成四部份，分别对应移动了1、2、4、8位
//S[i]每一位代表的移位量不同

if (S[0]) X = 左移1位; else X = DIN;
if (S[1]) Y = X左移2位; else Y = X;
if (S[2]) Z = Y左移4位; else Z = Y;
if (S[3]) DOUT = Z左移8位; else DOUT = Z;
```

```verilog
module Vrrol16(DIN,S,DOUT);
	input [15:0] DIN;
	input [3:0] S;//左移的位数
	output [15:0] DOUT;
	reg [15:0] DOUT,X,Y,Z;
	
	always@(DIN or S) begin
		if(S[0]==1'b1) X={DIN[14:0],DIN[15]};//左移1位
		else X=DIN;
		if(S[1]==1'b1) Y={X[13:0],X[15:14]};//左移2位
		else Y=X;
		if(S[2]==1'b1) Z={Y[11:0],Y[15:12]};//左移4位
		else Z=Y;
		if(S[3]==1'b1) DOUT={Z[7:0],Z[15:8]};//左移8位
		else DOUT=Z;
	end
endmodule
```

## 左右循环移位的16位桶状移位器-行为级case

```verilog
module Vrrol16(DIN,S,DIR,DOUT);
	input [15:0] DIN;
	input [3:0] S;//移位位数0-15
	input DIR;//DIR为0时左移，为1时右移
	output [15:0] DOUT;
	reg [15:0] DOUT,X,Y,Z

	//两个控制信号，可以在上一个移位器的基础上做更改
	//用DIR分别和S的4位做编码，然后用多个case语句
	
	always@(*) begin
		//移动1位
		case({S[0],DIR})
			2'b00,2'b01:X=DIN;
			2'b10:X={DIN[14:0],DIN[15]};
			2'b11:X={DIN[0],DIN[15:1]};
			default:X=16'bx;
		endcase
		//移动2位
		case({S[1],DIR})
			2'b00,2'b01:Y=X;
			2'b10:Y={X[13:0],X[15:14]};
			2'b11:Y={X[1:0],X[15:2]};
			default:Y=16'bx;
		endcase
		//移动4位
		case({S[2],DIR})
			2'b00,2'b01:Z=Y;
			2'b10:Z={Y[11:0],Y[15:12]};
			2'b11:Z={Y[3:0],Y[15:4]};
			default:Z=16'bx;
		endcase
		//移动8位
		case({S[3],DIR})
			2'b00,2'b01:DOUT=Z;
			2'b10:DOUT={Z[7:0],Z[15:8]};
			2'b11:DOUT={Z[7:0],Z[15:8]};
			//这个左移右移的结果都是一样的
			default:DOUT=16'bx;
		endcase
	end
endmodule
```

# 算数移位与逻辑移位

## 用算数右移与符号位拓展

算数右移的核心：**高位补符号位，而不是补0**。这使得移位后数值的符号不变。

最简单的例子——把8位有符号数拓展到16位：

```verilog
// 8位有符号数 a = 8'b1101_0010 （负数，-46）
// 要把它拓展为16位，符号位必须延续

// 逻辑右移（错误！）——高位补0，负数变正数
wire [15:0] logical = {8'b0, a};        
// 16'b0000_0000_1101_0010 → 正数，错了

// 算数右移（正确！）——高位补符号位1
wire [15:0] arithmetic = {{8{a[7]}}, a}; //使用了复制操作
// 16'b1111_1111_1101_0010 → 仍然是负数
```

## 算数移位 vs 逻辑移位：Verilog 写法对比

Verilog 中用操作符区分：

| 操作 | 逻辑移位 | 算数移位 |
|------|---------|---------|
| 左移 | `<<` 或 `<<<` | `<<<`（两者等价） |
| 右移 | `>>` | `>>>` |

**左移时两者完全一样**——高位移出，低位补0，没有符号位的概念。

**右移时区别在于高位补什么：**

```
逻辑右移 >>   高位补0     → 无符号数使用
算数右移 >>>  高位补符号位 → 有符号数使用
```

### 同一个8位数，两种右移的对比

>[!tips]
a = 8'b1011_0100   （作为有符号数 = -76）
a >> 3   逻辑右移  →  8'b0001_0110   = 22  
（高位补0，符号丢失）
a >>> 3  算数右移  →  8'b1111_0110   = -10  
（高位补符号位1，数值÷8≈-9.5，向下取整）


### 对应的电路差异

逻辑右移器只需要 **0 填充**，而算数右移器需要**将输入的最高位（符号位）复制到所有空出的高位**：

```
逻辑右移器（4位）:
  S[1:0] = 10（右移2位）
  输入:  1 0 1 1
  输出:  0 0 1 0   ← 高位补0

算数右移器（4位）:
  S[1:0] = 10（右移2位）
  输入:  1 0 1 1   （符号位 = 1）
  输出:  1 1 1 0   ← 高位补符号位1
```

实现上，算数右移器只需要把逻辑右移器中**空出的高位从固定接0改为接输入的符号位 `DIN[N-1]`** 即可，其余结构完全相同。
