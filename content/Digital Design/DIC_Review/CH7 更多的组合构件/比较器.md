# 比较器概述

在计算机系统里，比如说指令执行的时候就需要通过比较操作码的方式来控制程序的行为，在设备接口中也会通过比较器来比较两个二进制字是否相等。这种仅仅比较两个二进制数是否相等的比较器称为比较器（comparator），而能指出字之间的算数关系(大于或小于)，这些器件常称为数值比较器(magnitude comparator)

# 比较器结构

一个异或门or同或门就可被视作1bit比较器。利用n个异或门和n输入的或门就可以构建一个n位比较器。

![[file-20260623094316282.png|634x280]]

如果A0=B0那么输出为0，在A和B完全相同的时候，DIFF输出为0，否则为1

也可以采用同或门来设计，但是在用同或门设计多位比较器的时候，需要在最后把输出AND在一起，这样在A=B的时候，DIFF输出为1，否则为0。

此处介绍的都是并行的电路，接下来介绍**迭代电路**。

# 迭代电路

“迭代”（Iterative）在硬件电路里，可以用“空间上的串行流水”或“行波（Ripple）”来理解。（**注意是组合电路**）
你现在看到的“并行比较器”就像是招了一群人，每个人负责比对其中一位，最后大家把结果汇聚到一处（通过一个大与门）。它的特点是速度快（并行），但位数多了之后连线和门电路会变得很庞大。
而迭代电路（Iterative Circuit）则是另一种思路：
它由多个结构完全相同的小逻辑单元（Cell）串联而成。每一次只处理一位的比较，并将这一位的比较结果（作为某种状态信息）传递给下一个单元。

![[file-20260623100059473.png|796]]

- **硬件本质**：如果循环需要执行 $n$ 次，硬件设计者直接在芯片上摆放 **$n$ 个一模一样的物理组合逻辑模块**（也就是图里说的相同单元）。
- **数据的流动**：
    - **模块 0** 拿到初始值 $C_0$ 和主输入 $PI_0$，立刻在空间上把结果 $C_1$ 传给右边的 **模块 1**；
    - **模块 1** 拿到 $C_1$ 和 $PI_1$，立刻又把结果 $C_2$ 传给右边的 **模块 2**；
    - ……以此类推，信号像波浪一样一直向右传。

数值比较器一般采用减法器来设计，无符号数的比较的话看最高位的借位，有符号的话看“差”的符号位

## 8位数值比较器的verilog(if-else)

```verilog
module Vr8bitcom(P,Q,PEQQ,PGTQ,PLTQ);
	input [7:0] P,Q;
	output reg PEQQ,PGTQ,PLTQ;
	always @(*) begin
		if(P==Q) 
			begin PEQQ=1'b1; PGTQ=1'b0; PLTQ=1'b0; end
		else if(P>Q)
			begin PEQQ=1'b0; PGTQ=1'b1; PLTQ=1'b0; end
		else if(P<Q)
			begin PEQQ=1'b0; PGTQ=1'b0; PLTQ=1'b1; end
		else
			begin PEQQ=1'bx; PGTQ=1'bx; PLTQ=1'bx; end
			//一定要写else，不然会推理出锁存器
	end
endmodule
```

以上的代码会综合出两个比较器，一个用于比较P>Q,另一个用于比较P<Q,由[[#数值比较器]]里的电路结构可以看出，PLTQ完全可以由前两种判断来推理是否有效，所以说可以写成

```verilog
module Vr8bitcom(P,Q,PEQQ,PGTQ,PLTQ);
	input [7:0] P,Q;
	output reg PEQQ,PGTQ,PLTQ;
	always @(*) begin
		if(P==Q) 
			begin PEQQ=1'b1; PGTQ=1'b0; PLTQ=1'b0; end
		else if(P>Q)
			begin PEQQ=1'b0; PGTQ=1'b1; PLTQ=1'b0; end
		else
			begin PEQQ=1'b0; PGTQ=1'b0; PLTQ=1'b1; end
	end
endmodule
```

## 8位comparator(数据流描述)

```verilog
module Vr8bitcom(P,Q,PEQQ,PGTQ,PLTQ);
	input [7:0] P,Q;
	output PEQQ,PGTQ,PLTQ;
	
	assign PGTQ = (P>Q)?1'b1:1'b0;
	assign PEQQ = (P==Q)?1'b1:1'b0;
	assign PEQQ = (P<Q)?1'b1:1'b0;//这里会多综合出一个比较器
	
endmodule
```

在相同的motivation下，8位比较器还可以写成

```verilog
module Vr8bitcom(P,Q,PEQQ,PGTQ,PLTQ);
	input [7:0] P,Q;
	output PEQQ,PGTQ,PLTQ;
	
	assign PGTQ = (P>Q)?1'b1:1'b0;
	assign PEQQ = (P==Q)?1'b1:1'b0;
	assign PEQQ = ~PGTQ & ~PEQQ;//这里会多综合出一个比较器
endmodule
```
