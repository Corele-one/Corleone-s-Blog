三态门(three-state buffer,后续描述我会用tri来表示3的意思)的三态包括:"0","1","高阻态(Hi-Z)"这三种状态之一的cmos器件的电气设计。在第三种状态下，三态门的行为就跟没有电路连接一样。

# 三态缓冲器

![[file-20260620231203105.png|318x258]]

使能端有效时，器件行为和反相器或者普通的缓冲器一样，但使能无效时，器件输出高阻态，在功能上像是不存在一样。所以可以用三态缓冲器来实现MUX，如下图所示：

![[file-20260620231541028.png|700x490]]

decoder输出独热选择信号来选择对应通路的数据进入总线当中，未被选中的tri-buffer输出高阻态，不会对总线上被选中的数据输出造成影响。但是因为三态门的某些电气特性不如MUX，所以在片上互连中很少使用三态门，更多的是把三态门用于片外系统，用三态门来设计控制逻辑

# 用Verilog实现三态输出

## 74x541verilog实现

```verilog
module Vr74x541(G1_L,G2_L,A,Y);
	input G1_L,G2_L;
	input [7:0] A;
	output [7:0] Y;
	assign Y= (~G1_L & ~G2_L)? A :8'bz;
endmodule
```

## 8位收发器的verilog代码实现
**A,B既可作为输入，又可作为输出，声明端口时声明为inout**

```verilog
module transceiver(G_L,DIR,A,B);
	input G_L,DIR;
	inout [7:0] A,B;//注意端口的声明
	assign B=(~G_L & DIR)?A:8'bz;
	assign A=(~G_L & ~DIR)?B:8'bz;
endmodule
```
