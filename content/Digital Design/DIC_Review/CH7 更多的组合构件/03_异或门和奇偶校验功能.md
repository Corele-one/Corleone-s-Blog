# 异或门的作用

异或门可以用来
1. 比较:比较两个数字是否相等
2. 奇偶发生和校验:一个多位的异或函数可以计“不带进位的二进制加法”
3. 加法:可以用异或函数来形成加法中和的各个二进制位
4. 计数：二进制计数器在计数时，采用异或来形成每一位的下一个值，可以用作T触发器的部件

多路复用器样式的设计经常用于ASIC电路中，第二种三级与非门的设计原理如下图所示

普通的异或公式写成“与或非”的形式是：
$$F = X \oplus Y = X\bar{Y} + \bar{X}Y$$
为了把它全部变成与非门（NAND），我们对整个式子**连续取两次反**（值保持不变）：
$$F = \overline{\overline{X\bar{Y} + \bar{X}Y}}$$
根据摩根定律（$\overline{A+B} = \bar{A} \cdot \bar{B}$），可以将里面的加号（或门）变成乘号（与门）：
我们有以下等式(可以根据$0+X\bar{Y}=X\bar{X}+X\bar{Y}=X(\bar{X}+\bar{Y})=X\cdot \overline{XY}$：
- $X\bar{Y} = X \cdot \overline{XY}$
- $\bar{X}Y = Y \cdot \overline{XY}$
$$F = \overline{\overline{X \cdot \overline{XY} + Y \cdot \overline{XY}}}$$
再次运用摩根定律，把中间的加号拆开：
$$F = \overline{\overline{X \cdot \overline{XY}} \cdot \overline{Y \cdot \overline{XY}}}$$

# 用verilog实现异或门和奇偶校验电路

## 三输入异或、数据流描述

```verilog
module XOR3(Y,A,B,C);
	input A,B,C;
	output Y;
	
	assign Y=A^B^C;
endmodule
```

## 9输入奇校验电路的行为级描述

```verilog
module parity9(I,ODD);
	input [8:0] I;
	output I;
	integer j;
	
	always @(*) begin
		ODD=1'b0;//对输出赋初值
		for(j=1;j<=9;j=j+1)
			if(I[j]) ODD=~ODD;
//行为级所描述的行为是遇到一个1，ODD的值就翻转，很像1bit二进制加法的行为，在加了偶数个1的时候输出为0，奇数个1的时候输出为1
	end
endmodule
```

## 结构级描述(Structral)

实例化数据流描述的异或门

```verilog
module parity9(I,ODD);
	input [8:0] I;
	output ODD;
	wire Y1,Y2,Y3;
	
	XOR3 U1(.Y(Y1),.A(I[0]),.B(I[1]),.C(I[2]));
	XOR3 U2(.Y(Y2),.A(I[3]),.B(I[4]),.C(I[5]));
	XOR3 U3(.Y(Y3),.A(I[6]),.B(I[7]),.C(I[8]));
	XOR3 U4(.Y(ODD),.A(Y3),.B(Y2),.C(Y1));
	
endmodule
```

# 奇偶校验

> [!warning] 易混淆辨析：产生校验位 vs 验证校验位
> 奇偶校验中，"偶校验"的定义始终是：**完整编码（数据+校验位）中 1 的总个数为偶数**。
> 但在**发送端（产生校验位）**和**接收端（验证校验位）**两个阶段，操作逻辑恰好相反：
>
> | | 产生校验位（发送端） | 验证校验位（接收端） |
> |---|---|---|
> | **偶校验** | 数数据中 1 的个数：**奇数→校验位=1**，偶数→校验位=0 | 数**全部**位中 1 的个数：**偶数→无错**，奇数→报错 |
> | **奇校验** | 数数据中 1 的个数：**偶数→校验位=1**，奇数→校验位=0 | 数**全部**位中 1 的个数：**奇数→无错**，偶数→报错 |
>
> **口诀**：产生校验位时"缺啥补啥"（凑成目标奇偶性）；验证时"符合即对"（总数符合目标奇偶性则无错）。

## 经典题型

![[file-20260705180831954.png|951]]

**题目大意**：接收方收到 9 位数据 `010011001`，且**没有报错**，问使用的是奇校验还是偶校验？

**解题思路（接收端 = 验证阶段）**：

1. 数 `010011001` 中 1 的个数：第1、4、5、8 位为 1 → 共 **4 个 1**（偶数）
2. 没有报错 → 当前总数的奇偶性 = 校验类型所要求的奇偶性
3. 4 是偶数 → 校验类型要求 1 的个数为偶数 → **偶校验（even parity）**

> [!tip] 做题时的关键判断
> 看到"**without error indicated / 无错误**" → 接收端验证通过 → 直接数全部 1 的个数，**偶数个 → 偶校验，奇数个 → 奇校验**。
> 看到"**error detected / 检测到错误**" → 说明不符合 → 反过来。
