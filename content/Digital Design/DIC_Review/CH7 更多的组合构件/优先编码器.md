# verilog实现优先编码器

## 多重if 

if-else中，优先级高的写前面，因为if else在嵌套过程中本就是一种优先级的表达。
而在后面用循环语句实现的if中，几个if语句是并列的，所以越往后的if语句的优先级越高。

## 行为级描述

### 用for语句简化if

```verilog
module priencoder(I,A,IDLE);
	input [7:0] I;
	output [2:0] A;
	output IDLE;
	integer i;
	
	always@(*) begin
		IDLE=1;A=0
		for(i==0;i<=7;i=i+1) begin
			if(I[i]==1) begin 
			//问题:为什么从I[0]开始if，这样会导致I[0的优先级最高吗]
				IDLE = 0;
				A=i;
			end
		end
	end
	
endmodule
```

对注释问题的解答：
#### 为什么 $I[7]$ 的优先级最高？
Verilog 中的 `always@(*)` 块里的 `for` 循环是**顺序执行(阻塞赋值)** 这意味着后面的赋值会**覆盖**前面的赋值。

我们来模拟一下当 `I = 8'b10000001`（即 $I[7]$ 和 $I[0]$ 同时为 1）时，循环是如何运行的：
- **当 `i = 0` 时：** 满足 `if (I[0] == 1)`，执行代码，此时 `A = 0`, `IDLE = 0`。
- **当 `i` 从 1 变到 6 时：** 不满足 `if` 条件，`A` 保持为 0。
- **当 `i = 7` 时：** 满足 `if (I[7] == 1)`，执行代码，此时 `A = 7`, `IDLE = 0`。
**结果：** 最终输出的 `A` 是 **7**。因为 `i = 7` 是最后执行的，它把之前 `i = 0` 时赋给 `A` 的值给覆盖（Overwrite）掉了。
> 💡 **总结规律：**
> 在这种正向遍历（`i` 从 0 到 7）且没有 `break` 的循环中，**越往后执行的条件，胜出权越大**。所以 $I[7]$ 拥有最高优先级。
### 行为级case

```verilog
module Vr8inprior4(I, A, IDLE);
    input [7:0] I;
    output reg [2:0] A;
    output reg IDLE;
    
    always @(*) begin
        IDLE = 1; A = 0;
        case (1'b1)//注意此处用常量来与输入对应的有效位来做匹配
            I[7]: begin IDLE = 0; A = 7; end
            I[6]: begin IDLE = 0; A = 6; end
            I[5]: begin IDLE = 0; A = 5; end
            I[4]: begin IDLE = 0; A = 4; end
            I[3]: begin IDLE = 0; A = 3; end
            I[2]: begin IDLE = 0; A = 2; end
            I[1]: begin IDLE = 0; A = 1; end
            I[0]: begin IDLE = 0; A = 0; end
        endcase
    end
endmodule
```

也可以采用casez语句来设计优先编码器，这样的设计方法是为了防止输入位出现高阻态z或不定态x的时候，有限编码器也能正常对有效位做正确的编码

```verilog
module Vr8inprior4(I, A, IDLE);
    input [7:0] I;
    output reg [2:0] A;
    output reg IDLE;
    
    always @(*) begin
        IDLE = 1; A = 0;
        casez (I)
            8'b1???_????: begin IDLE = 0; A = 7; end
            8'b?1??_????: begin IDLE = 0; A = 6; end
            8'b??1?_????: begin IDLE = 0; A = 5; end
            8'b???1_????: begin IDLE = 0; A = 4; end
            8'b????_1???: begin IDLE = 0; A = 3; end
            8'b????_?1??: begin IDLE = 0; A = 2; end
            8'b????_??1?: begin IDLE = 0; A = 1; end
            8'b????_???1: begin IDLE = 0; A = 0; end
        endcase
    end
endmodule
```
