### 串入串出(SISO)的verilog实现
*右移*
```verilog
module shift_reg_siso #(
    parameter N = 8  // 移位寄存器位数
)(
    input  wire SERIN,   // 串行输入
    input  wire CLOCK,   // 时钟
    output wire SEROUT   // 串行输出
);

    reg [N-1:0] shift_reg;

    // 每个时钟沿，数据向右移一位，SERIN进入最高位
    always @(posedge CLOCK) begin
        shift_reg <= {SERIN, shift_reg[N-1:1]};
    end

    // SEROUT 为最低位
    assign SEROUT = shift_reg[0];

endmodule

```

### 串入并出移位寄存器的verilog模块

*左移*

```verilog
module SIPO(CLK,CLR,SERIN,Q);
	input CLK,CLR,SERIN;
	parameter WID=8;//参数化设计
	output reg [WID-1:0] Q;
	always@(*) begin
		if(CLR)
			Q<=0；
		else
			Q<={Q[WID-2:0]，SERIN};
	end
endmodule
```
## 通用4位移位寄存器verilog模块

通过选择控制端 S1、S0 的不同组合，实现多种工作模式：

| S1  | S0  | 功能   | 说明                         |
| --- | --- | ---- | -------------------------- |
| 0   | 0   | 保持   | 寄存器内容不变                    |
| 0   | 1   | 右移   | RIN 移入 QA，QA→QB→QC→QD 方向移位 |
| 1   | 0   | 左移   | LIN 移入 QD，QD→QC→QB→QA 方向移位 |
| 1   | 1   | 并行加载 | A、B、C、D 同时载入 QA、QB、QC、QD   |

```verilog
module Vrshrgu4(CLK, CLR, RIN, LIN, S0, S1, A, B, C, D, QA, QB, QC, QD);
    input CLK, CLR, RIN, LIN, S0, S1, A, B, C, D;
    output reg QA, QB, QC, QD;
    always @(posedge CLK) begin
        if (CLR == 1'b1)
            {QA, QB, QC, QD} <= 4'b0;
        else case ({S1, S0})
            2'b00 : {QA, QB, QC, QD} <= {QA, QB, QC, QD};    
            // 保持
            2'b01 : {QA, QB, QC, QD} <= {RIN, QA, QB, QC};   
            // 右移
            2'b10 : {QA, QB, QC, QD} <= {QB, QC, QD, LIN};   
            // 左移
            2'b11 : {QA, QB, QC, QD} <= {A, B, C, D};
            // 并行加载
            default: {QA, QB, QC, QD} <= 4'bx;
        endcase
    end
endmodule
```

## 扩展后的8位移位寄存器的verilog模块

在4位通用移位寄存器基础上，增加循环移位和算术移位功能，使用 3 位选择端 S 控制 8 种模式：
**注意算术右移**

| S    | 功能   | 说明                |
| ---- | ---- | ----------------- |
| 3'd0 | 保持   | 寄存器内容不变           |
| 3'd1 | 并行载入 | D[7:0] 一次性载入 Q    |
| 3'd2 | 右移   | RIN 移入最高位 Q[7]    |
| 3'd3 | 左移   | LIN 移入最低位 Q[0]    |
| 3'd4 | 循环右移 | Q[0] 移入 Q[7]，其余右移 |
| 3'd5 | 循环左移 | Q[7] 移入 Q[0]，其余左移 |
| 3'd6 | 算术右移 | 最高位保持符号位不变，其余右移   |
| 3'd7 | 算术左移 | 最低位补 0，其余左移       |

```verilog
module Vrshrg8ext(CLK, CLR, RIN, LIN, S, D, Q);
    input CLK, CLR, RIN, LIN;
    input [2:0] S;
    input [7:0] D;
    output reg [7:0] Q;

    always @(posedge CLK)
        if (CLR == 1) Q <= 0;
        else case (S)
            3'd0: Q <= Q;                    // 保持
            3'd1: Q <= D;                    // 并行载入
            3'd2: Q <= {RIN, Q[7:1]};        // 右移
            3'd3: Q <= {Q[6:0], LIN};        // 左移
            3'd4: Q <= {Q[0], Q[7:1]};       // 循环右移
            3'd5: Q <= {Q[6:0], Q[7]};       // 循环左移
            
            3'd6: Q <= {Q[7], Q[7:1]};       
            // 算术右移(符号位保留)
            3'd7: Q <= {Q[6:0], 1'b0};       
            // 算术左移(低位补0)
            default: Q <= 8'bx;
        endcase
endmodule
```

> **循环移位 vs 算术移位的区别：**
> - **循环移位**：移出的位绕回另一端，总位数不变，无信息丢失
> - **算术移位**：右移时保持符号位（MSB）不变用于有符号数除2；左移时低位补0用于有符号数乘2

**SHRG4U的功能示意**
==QA、QB、QC、QD==中，QA为最高位，用代码就是
```verilog
reg [3:0] Q;
Q={QA,QB,QC,QD};//仅做示意
所以QA对应Q[3],QD对应Q[1]

所以左移的时候，是把最高位QA循环移位到最低位，
右移的时候是把最低位QD循环移位到最高位
```

| S1  | S0  | 功能   | 说明                         |
| --- | --- | ---- | -------------------------- |
| 0   | 0   | 保持   | 寄存器内容不变                    |

### 自校正环形计数器的verilog代码
```verilog
module Shift(CLK,INIT,CNTEN,S);
	input CLK,INIT,CNTEN;
	output reg [7:0] S;
	
	always@(posedge CLK) begin
		if(INIT==1)
			S<=8'b0000_0001;//同步初始化
		else if(CNTEN)
			S<={S[6:0],&(~S[6:0])};//移位+自同步逻辑
		else 
			S<=S;
	end
endmodule
```

#### 自同步逻辑拆解

`{S[6:0], &(~S[6:0])}` 这一行同时做了两件事：**左移** + **自同步注入**

核心是 `&(~S[6:0])` 这个 expression，拆开来看：

```
~S[6:0]     →  逐位取反
&(…)        →  reduction AND，所有位相与
```

所以 `&(~S[6:0])` = `~S[6] & ~S[5] & … & ~S[0]`，**只有当 S[6:0] 全为 0 时才输出 1**。

这本质上是一个 **7 输入 NOR 门**：检测低 7 位是否全零。

可以用 `assign` 把这个自同步信号提取出来，逻辑更清晰：

```verilog
wire self_sync; // 低7位全零时为1，否则为0
assign  self_sync= &(~S[6:0]);

always @(posedge CLK) begin
    if (INIT)
        S <= 8'b0000_0001;
    else if (CNTEN)
        S <= {S[6:0], self_sync}; // 左移 + 自同步注入
end
```

==自同步的含义==：正常工作时（状态 `0000_0001` → `0000_0010` → …），`S[6:0]` 不全为 0，`self_sync = 0`，移入的是 0，和普通环形计数器一样。一旦丢失所有 1（如全零状态 `0000_0000`），`self_sync = 1`，自动注入一个 1 到最低位，把状态拉回有效循环，无需外部 RESET 信号。

## Johnson计数器(扭环型计数器)
之前的环形计数器的==有效状态数为4==，以下介绍扭环式计数器
把n位移位寄存器的串行输出取反，反馈到串行输入端

![[file-20260629163558965.png|400]]

![[file-20260629164622288.png|674]]
n位环形计数器只有n个有效状态，而n位扭环形计数器可以有2n个状态，环形计数器也同样存在着稳定性问题。
### 扭环计数器Verilog设计(无自校正)
```verilog
module Johnson(CLK,rst_n,Q);
	parameter N;//参数化设计
	input CLK,rst_n;
	output reg [N-1:0] Q;
	always @(posedge CLK) begin
		if(~rst_n)//低电平有效
			Q<=8'b0;
		else
			Q<={Q[N-2:0],~Q[N-1]};//左移，最低位=~最高位
	end
endmodule
```
### 自校准扭环形计数器

![[file-20260629165621267.png|500]]

#### 为什么需要自校正？

n位 Johnson 计数器有 $2^n$ 个状态，但只有 **2n 个有效状态**，存在 $2^n - 2n$ 个无效状态。4 位 Johnson 计数器有 16 个状态，仅 8 个有效，剩下 8 个无效状态会形成**封闭死循环**，上电后一旦落入就永远无法回到有效循环：

```
有效循环(8个):
0000 → 0001 → 0011 → 0111 → 1111 → 1110 → 1100 → 1000 → 0000

无效死循环(8个):
0010 → 0101 → 1011 → 0110 → 1101 → 1010 → 0100 → 1001 → 0010
```

#### 电路设计

NOR 门的真值表：

| QA | QD | NOR | 模式 |
|:--:|:--:|:---:|:----:|
| 0 | 0 | **1** | 并行加载 0001 |
| 0 | 1 | 0 | 正常左移 |
| 1 | 0 | 0 | 正常左移 |
| 1 | 1 | 0 | 正常左移 |

==核心思路：NOR 门只在状态为 `0xx0`（MSB=0 且 LSB=0）时输出 1，触发并行加载，将计数器拉回有效循环。其余时候正常左移，不影响 Johnson 计数器的正常工作。==

#### 为什么所有无效状态都能被校正？

**关键观察**：`0xx0`（MSB=0 且 LSB=0）这个位模式几乎是无效状态特有的标志位——在 8 个有效状态中，只有初始态 `0000` 具备该模式，而 `0000` 本就会被置数到 `0001`（同样是有效状态），不影响有效循环的完整性。

虽然并非所有无效状态一开始就是 `0xx0`，但左移操作会将无效状态中的 `1→0` 跳变逐步推向高位，最终必然产生 `0xx0` 模式：

以两个无效状态为例：

```
1101 → 左移(LIN=0) → 1010  ← 第1拍，出现 10xx
1010 → 左移(LIN=0) → 0100  ← 第2拍，出现 0xx0
0100 → NOR=1，加载 → 0001  ← 第3拍，校正完成 ✓

0101 → 左移(LIN=1) → 1011  ← 第1拍，出现 10xx
1011 → 左移(LIN=0) → 0110  ← 第2拍，出现 0xx0
0110 → NOR=1，加载 → 0001  ← 第3拍，校正完成 ✓
```

==所有 8 个无效状态，最多 3 拍（n-1 拍）内必定回到有效循环。==
#### 总结

> 自校正 Johnson 计数器 = 标准 Johnson + 1 个 NOR 门
> - 硬件代价极小（仅增加一个 2 输入 NOR 门）
> - 校正时间：最多 n 拍
> - NOR 门不需要识别所有无效状态，只需在移位过程中截住必然出现的 `0xx0` 模式

## 线性反馈移位寄存器型计数器(LFSR)

LFSR的有效状态数为$2^n-1$，这种计数器也被称为*最大长度序列发生器*

### 3位LFSR的原理

对全零状态可以引入蓝色部分的反馈电路，使得在Q2,Q1,Q0都为0的时候，电路仍然能够正常计数

![[file-20260629202849368.png|844]]

#### 原始 LFSR 的反馈

原始反馈为 **LIN = X1 ⊕ X0**，移位方式为右移 `{X2, X1, X0} <= {LIN, X2, X1}`。

原始 7 状态循环（跳过了 000）：

```
100 → 010 → 101 → 110 → 111 → 011 → 001 → 100
```

#### NOR 门做了什么？

NOR 门监测 **X2 和 X1**，当 X2=0 且 X1=0 时输出 1。这个输出与原始 XOR 反馈再做一次异或：

```
最终 LIN = (X1 ⊕ X0) ⊕ NOR(X2, X1)
```

**当 X2=0, X1=0 时**（状态为 000 或 001），NOR=1：

```
LIN = (X1 ⊕ X0) ⊕ 1 = ~(X1 ⊕ X0)    ← 反馈被取反！
```

具体效果：

| 状态 | 原始反馈 X1⊕X0 | NOR | 修改后 LIN | 下一状态 |
|:----:|:-------------:|:---:|:---------:|:-------:|
| 000 | 0⊕0 = **0** | 1 | 0⊕1 = **1** | **100**（逃出锁死） |
| 001 | 0⊕1 = **1** | 1 | 1⊕1 = **0** | **000**（先进 000） |

**当 X2, X1 不同时为 0 时**（其余 6 个状态），NOR=0：

```
LIN = (X1 ⊕ X0) ⊕ 0 = X1 ⊕ X0    ← 与原始反馈完全一致
```

所以这 6 个状态的行为和原始 LFSR **完全相同**，计数器工作不受影响。

原始序列跳过 000（7 状态）：`... → 001 → 100 → ...`
修改后序列包含 000（8 状态）：`... → 001 → 000 → 100 → ...`

|   X2   | X1  | X0  |   X2   |  X1   |  X0   |
