## 行波计数器
一个T触发器(时钟边沿到来时输出翻转)实际上就是一个模为2的计数器

![[file-20260514104212237.png|365x480]]

其中低位的Q‘作为高位的时钟，当低位从1->0的时候，需要向前进位，所以说把Q‘(从0->1为上升沿)作为时钟接入高位的时钟，就能实现向高位的进位，这个变化符合一般的二进制计数顺序。
如果要实现==减法==的计数器的话，只需把**Q端作为时钟**接入高位即可。

但是本质上这种计数器的构成方式还是**异步**的，在真实情况下，我们希望得到一个同步的计数器。因为如果采用异步计数器的话，每个触发器需要等它前一级完成翻转后才能触发，会造成延时并且位数越多延时越大。

时钟周期需要>所有触发器延时之后，否则在低位没有稳定的时候下一个时钟沿又来了。
## 同步四位二进制计数器

在同步计数器中，所有触发器都共用一个CLK信号，因此在经过仅仅$t_{TQ}$的延迟后，所有触发器的输出同时发生变化。此时采用带有使能输入端的T触发器。

## 4位通用二进制计数器CNTR4U

![[file-20260628123258428.png]]

其中，ENP为计数使能，ENT为进位使能，LD为置数使能，CLR为清零使能，用verilog语言描述该模块的功能如下：
注意清零、置数信号为**同步清零**和**同步置数**信号
```Verilog
modeule Vrcntr4u(CLK,CLR,LD,ENP,ENT,D,Q,RCO);
	input CLK,CLR,LD,ENP,ENT;
	input [3:0] D;
	output reg [3:0] Q;
	output reg RCO;
	//创建该计数器的特性
	always @(posedge CLK) begin
		if(CLR == 1) begin
			Q<=4'd0;
		end
		else if(LD==1) begin
			Q<=D;
		end
		else if((ENP==1)&&(ENT==1)) begin
			Q<=Q+1;
		end
		else begin
			Q<=Q;
		end
	end
	//创建组合输出RCO
	always@(Q or ENT) begin
		if((ENT==1)&&(Q==4'd15)) begin
			//ENT使能时才进位
			RCO=1;
		end
		else begin
			RCO=0;
		end
	end
```


### 修改该模块获得十进制计数器

![[file-20260514112553207.png|950]]

*注意异步和同步的区别*
因为CNTR4U芯片是同步置数，所以4'd9会出现在Q值当中。
如果是异步置数的话，4’d9就不会出现在Q中，因为如果是异步的话，当Q一为4'd9的时候，Q就清零，不需要等时钟，所以Q不会出现在Q的计数序列中。可以根据这一逻辑来编写代码的边界条件。

![[file-20260628124217846.png]]

### 译码器输出的毛刺（Glitch）问题

**核心原因**：当计数器状态转移中有**两个或两个以上的位同时变化**时（例如 011→100，三个位全变），由于译码器内部不同信号通路的延迟不同（例如 A1→Y1\_L 比 A0→Y1\_L 快），译码器会**短暂地出现一个错误的中间输出**，表现为某个输出端产生一个窄脉冲——即**毛刺（glitch）**。

> 本质：多个输入位同时翻转 → 各通路延迟不同 → 译码器暂时"看到"错误输入 → 输出端闪一下

**毛刺是否有害取决于下游器件**：

| 下游器件 | 是否受影响 | 原因 |
| --- | --- | --- |
| 边沿触发器件（寄存器、计数器 CLK/CE） | **无害** | 毛刺在时钟沿采样前已消失 |
| 电平敏感器件（$\bar{S}$-$\bar{R}$ 锁存器的 S\_L / R\_L） | **有害** | 毛刺会被当作有效信号锁存 |

### 消除毛刺的方法

![[file-20260628124827674.png]]

如图 11-10，在译码器输出端**再接一个 8 位寄存器**，用同一个时钟 CLK 采样。寄存器**只在时钟沿捕获已经稳定的译码输出**，因此输出 RS0\_L ~ RS7\_L 是干净无毛刺的。

> 更经济的替代方案：使用**环形计数器（ring counter）**，它可以直接产生无毛刺的译码输出。

#### 寄存器型译码器的verilog模型

```verilog
module CountDec(CLK,CLR,S_L);
	input CLK,CLR;
	output reg [7:0] S_L;
	reg [2:0] Q;
	integer i;

	always@(posedge CLK) begin
		if(CLR) 
			Q<=3'd0;
		else    
			Q<=Q+1;
		S_L<=8'b1111_1111;//译码器的输出低电平有效
		for(i=0;i<=7;i=i+1)
			if(Q==i) S_L[i]<=0;//译码器的行为级描述
	end
endmodule
```

> ⚠️ **Verilog 综合注意事项：always 块中必须对信号的所有分支赋值**
>
> 上面的代码在 `if(Q==i)` 时给 `S_L[i]` 赋 0，但**没有 else 分支**。综合工具会认为"S_L[i] 有时候要保持原值"，从而推断出**锁存器（latch）
>
  修改方式**（加上 else，确保每个时钟沿都给 S_L[i] 明确赋值）：
  
```verilog
for(i=0; i<=7; i=i+1)
	if(Q==i) S_L[i] <= 1'b0;
	else     S_L[i] <= 1'b1; 
	 // 必须有 else，防止推断出 latch
```


## 4位递增/递减的计数器

```verilog
module Counter4(CLK,CLR,LD,ENP,ENT,UPDN,D,Q,RCO);
	input CLK,CLR,LD,ENP,ENT,UPDN;
	input [3:0] D;
	output reg [3:0] Q;
	output RCO;
	
	always@(posedge CLK) begin
		if(CLR==1)
			Q<=4'b0;
		else if(LD==1)
			Q<=D;
		else if(ENP&&ENT&&UPDN)
			Q<=Q+1;
		else if(ENP&&ENT&&!UPDN)
			Q<=Q-1;
		else
			Q<=Q;
	end
	
	always@(Q,ENT,UPDN) begin
		if(ENT&&Q=4'd15&&UPDN)
			RCO=1;
		else if(ENT&&Q=4'd0&&!UPDN)
			RCO=1;
		else
			RCO=0;
	end
endmodule
```

## 4位计数器的测试平台(testbench)

### 时钟生成的注意事项

```verilog
// ❌ 原始写法：CLK 前 5.5ns 为 x（未初始化）
always begin
    #5.5 CLK = 0;
    #4.0 CLK = 1;
    #0.5 ;
end

// ✅ 正确写法：先初始化 CLK，再用 always 翻转
initial CLK = 0;
always begin
    #5.0 CLK = ~CLK;  // 每 5ns 翻转，周期 10ns，占空比 50%
end
```

> ⚠️ `reg` 的默认初始值是 `x`（未知态），不加 `initial CLK = 0` 的话，仿真前几 ns 时钟是未知的，可能导致被测模块行为异常。

### 完整的 TB 文件

```verilog
`timescale 1ns/100ps

module VrcntrTB1();
    reg CLK, CLR, LD, ENP, ENT, UPDN;
    reg [3:0] D;
    wire [3:0] Q;
    wire RCO;

    // ========== 时钟生成：周期 10ns ==========
    initial CLK = 0;
    always begin
        #5.0 CLK = ~CLK;
    end

    // ========== 被测模块实例化 ==========
    cntr4u U0(
        .CLK(CLK), .CLR(CLR), .LD(LD),
        .ENP(ENP), .ENT(ENT),
        .D(D), .Q(Q), .RCO(RCO)
    );

    
    // ========== 测试激励 ==========
    initial begin
        // 初始化所有输入
        CLR = 0; LD = 0; ENP = 0; ENT = 0;
        D = 0; UPDN = 0;

        #105;                          
        // 等待FPGA全局复位结束

        // ① 清零：确认 CLR 有效
        CLR = 1; D = 4'b1111; #10;
        // 此时 Q 应为 0000（同步清零）

        // ② 置数：载入 1111
        CLR = 0; LD = 1; #10;
        // 此时 Q 应为 1111 = 15

        // ③ 仅 ENP=1，ENT=0：不计数
        LD = 0; ENP = 1; #10;
        // Q 保持 15（ENT 未使能）

        // ④ 开始递增计数（4 个时钟沿）
        ENT = 1; UPDN = 1; #40;
        // Q: 15→0→1→2→3

        // ⑤ 切换为递减计数（6 个时钟沿）
        UPDN = 0; #40;
        // Q: 3→2→1→0→15→14

        // ⑥ 再切换为递增计数（20 个时钟沿）
        UPDN = 1; #200;

        // ⑦ 停止计数
        ENP = 0; #30;
        $stop(1);
    end
endmodule
```
