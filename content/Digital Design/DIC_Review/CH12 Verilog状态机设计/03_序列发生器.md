>[!question]
>用Verilog设计一个序列发生器110010

# 法1: 移位寄存器预置序列，循环移位

**思路**：用一个 6 位移位寄存器，在复位时预置目标序列 `110010`，之后每个时钟沿将最高位循环移出，同时将最低位环回至最高位，实现序列的循环输出。

```verilog
module seq_gen(clk,rst_n,seq_out);
    input clk,rst_n;
    output seq_out;
    reg [5:0] Q;

    always@(posedge clk)
        if(~rst_n)
            Q<=6'b110010;
        else
            Q<={Q[4:0],Q[5]};
    assign seq_out<=Q[5];
endmodule
```

> [!tip] 特点
> - 结构最简单，只需要一个移位寄存器 + 组合拼接
> - 序列长度固定为寄存器位数（此处为 6 位）
> - 缺点：不够灵活，修改序列需要重新设计寄存器位宽和预置值

# 法2: 计数器 + 组合逻辑查表

**思路**：用一个模 6 计数器产生 `0~5` 的循环计数值，再用 `case` 语句根据当前计数值通过组合逻辑查表输出对应的序列位。计数器负责"数节拍"，组合逻辑负责"映射输出"。

```verilog
module seq_gen_counter (
    input       clk,      // 时钟
    input       rst_n,    // 异步复位，低有效
    output reg  seq_out   // 序列输出
);
    reg [2:0] cnt;        // 计数器：0 ~ 5 循环

    // 时序逻辑：模6计数器
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            cnt <= 3'd0;
        else if (cnt == 3'd5)
            cnt <= 3'd0;
        else
            cnt <= cnt + 1'b1;
    end

    // 组合逻辑：根据计数值输出对应的序列位
    always @(*) begin
        case (cnt)
            3'd0: seq_out = 1'b1;
            3'd1: seq_out = 1'b1;
            3'd2: seq_out = 1'b0;
            3'd3: seq_out = 1'b0;
            3'd4: seq_out = 1'b1;
            3'd5: seq_out = 1'b0;
            default: seq_out = 1'b0;
        endcase
    end
endmodule
```

> [!tip] 特点
> - 时序逻辑（计数器）与组合逻辑（输出映射）分离，结构清晰
> - 修改序列只需改 `case` 表，不需要改动计数器逻辑
> - 计数器的位宽由序列长度决定（6 位序列 → 3 位计数器）
> - 注意：组合逻辑输出为**异步**，随 `cnt` 变化立即变化，不是寄存器输出

# 法3: 有限状态机（FSM），6 个状态循环转移

**思路**：为序列的每一位分配一个状态（共 6 个状态），状态之间按顺序循环转移。每个状态对应一个固定输出，用三段式 FSM 实现：状态寄存器 + 次态逻辑 + 输出逻辑。

```verilog
module seq_gen_fsm (
    input       clk,
    input       rst_n,
    output reg  seq_out
);
    // 状态编码
    parameter [2:0] S0 = 3'b000,  // 输出 1
                    S1 = 3'b001,  // 输出 1
                    S2 = 3'b010,  // 输出 0
                    S3 = 3'b011,  // 输出 0
                    S4 = 3'b100,  // 输出 1
                    S5 = 3'b101;  // 输出 0

    reg [2:0] current_state, next_state;

    // ① 状态寄存器（时序逻辑）
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            current_state <= S0;
        else
            current_state <= next_state;
    end

    // ② 次态逻辑（组合逻辑）
    always @(*) begin
        case (current_state)
            S0: next_state = S1;
            S1: next_state = S2;
            S2: next_state = S3;
            S3: next_state = S4;
            S4: next_state = S5;
            S5: next_state = S0;
            default: next_state = S0;
        endcase
    end

    // ③ 输出逻辑（组合逻辑）
    always @(*) begin
        case (current_state)
            S0: seq_out = 1'b1;
            S1: seq_out = 1'b1;
            S2: seq_out = 1'b0;
            S3: seq_out = 1'b0;
            S4: seq_out = 1'b1;
            S5: seq_out = 1'b0;
            default: seq_out = 1'b0;
        endcase
    end
endmodule
```

> [!tip] 特点
> - 采用经典的**三段式** FSM 写法（状态寄存器 → 次态逻辑 → 输出逻辑），代码可读性强
> - 每个状态只产生一位输出，状态名本身即语义（S0~S5），便于调试和扩展
> - FSM 方法最为通用：当序列不再简单循环（如加入条件跳转、输入控制）时，FSM 是唯一能胜任的方案
> - 缺点：状态数 = 序列长度，对于很长的序列，状态编码位宽和逻辑资源开销较大

# 三种方法对比

| | 法1 移位寄存器 | 法2 计数器+查表 | 法3 状态机 |
|---|---|---|---|
| **核心思想** | 预置序列，循环移位 | 计数器节拍 + 组合逻辑映射 | 每位一个状态，顺序跳转 |
| **代码复杂度** | 最低 | 中等 | 最高 |
| **灵活性** | 低（改序列要改寄存器） | 中（改 case 表即可） | 高（可加复杂控制逻辑） |
| **适用场景** | 简单固定循环序列 | 简单固定序列，需分离计数与输出 | 复杂序列、含条件分支的序列 |
| **硬件资源** | 6 个触发器 | 3 个触发器 + 组合逻辑 | 6 个触发器 + 次态/输出逻辑 |
