使用generate循环生成多个子模块
```verilog
	genvar i;//指定循环变量
	generate
        for (i = 0; i < 100; i = i + 1) begin : reverse_loop//必须命名  
			……//需要实例化的模块或者想要实现的逻辑功能
        end
    endgenerate
```
实例：位反转模块
```verilog
module bit_reverse_generate (
    input  [99:0] in,
    output [99:0] out
);

    genvar i;  // 必须是 genvar，编译时常量
    
    generate
        for (i = 0; i < 100; i = i + 1) begin : reverse_loop //必须命名 
            assign out[i] = in[99 - i];  // 连续赋值，不是过程赋值
        end
    endgenerate

endmodule
```
