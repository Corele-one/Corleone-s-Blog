# Corleone's Notes

这里是我的微电子与电路方向学习笔记库，内容主要围绕模拟电路、数字设计、信号与系统、存内计算和器件学习展开。

站点地址：<https://corele-one.github.io/Corleone-s-Blog/>

## 内容导航

### Analog

`content/Analog/` 收录模拟电路相关笔记，重点包括：

- 二阶电路、RLC 电路与暂态响应
- 运算放大器基础与典型电路
- BJT、小信号模型、频率响应与反馈分析
- 课程中常见分析方法与推导整理

### Digital Design

`content/Digital Design/` 是当前内容最丰富的部分，主要整理数字 IC 与 Verilog 学习资料。

- `HDL_Verilog/`：Verilog 语法、组合逻辑、时序逻辑、FSM、`wire`/`reg`、循环语句、数组、操作符等专题笔记
- `Course Note/`：课程笔记，包括计数器、状态机、流水线、阻塞与非阻塞赋值、同步/异步设计等内容
- `DIC_Review/`：数字 IC 复习资料，按章节整理组合算数元件、状态机、时序逻辑元件、计数器、移位寄存器等内容

### Signal and System

`content/Signal and System/` 整理信号与系统课程内容，包含：

- 连续时间傅里叶变换
- 离散时间傅里叶变换
- 时域与频域分析
- 通信系统相关笔记
- 对偶性、系统响应等专题

### CIM

`content/CIM/` 用于整理存内计算相关资料，包括 Memory-Centered Calculation、架构概念、课程/论文阅读中的图示和笔记。

### Device Note

`content/Device Note` 和 `content/device_note.pdf` 保存器件方向学习笔记，作为半导体器件、电路基础和课程资料的补充。

### Cheatsheets

根目录下还有一些工具速查笔记：

- `content/Latex Cheatsheet.md`
- `content/Markdown Cheatsheet.md`
- `content/Terminal for MAC.md`

这些文件主要用于记录写作、排版和日常终端操作中的常用命令与语法。

## 笔记特点

- 内容以课程学习和复习为主，偏向可直接查阅的知识点整理。
- 数字设计部分包含较多 Verilog 代码片段和电路设计例题。
- 部分笔记配有图片、PDF 和课堂资料，资源通常放在同级 `assets/` 目录中。
- 笔记使用 Obsidian 风格双链组织，适合通过目录、搜索和知识图谱快速定位。
